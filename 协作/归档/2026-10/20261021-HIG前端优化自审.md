# 2026-10-21 HIG 前端优化自审

## 来源与技能

- 查阅 Apple 官方 HIG 的 Layout、Typography、Accessibility、Sidebars、Buttons、Dark Mode，链接及适用边界见 `docs/专题/界面设计规范.md`。
- 安装社区技能 `dickwu/apple-design-skill` 到用户 Codex skills 的 `apple-design`，含 124 个 HIG 参考文件；安装 `nextlevelbuilder/ui-ux-pro-max-skill` 的 `.claude/skills/ui-ux-pro-max` 到同名用户技能目录。下一次新会话可自动发现。
- apple-design 安装仓库提交：`914b6a377c22755597e4405e54911b996de822d7`；ui-ux-pro-max 查询时 main HEAD：`56ea9cf174ed86786187daa9de0e6247cb0747e4`。全局技能文件不加入项目 Git。
- 两个 SKILL.md 的 SHA256 分别为 `640BA168F05E84736ACBC54889ADB14F0EBE9FFBA913FA6DABD7CC72C24A6255`、`88AADD21220542083A455E373BD162FFE7843266A71F06F4D837BB3B34F9C9C7`。检查入口、参考文档和本地搜索脚本后使用；未运行外部参考刷新脚本。
- UI 搜索的两份设计系统结果偏营销落地页，未套用该结构；采用相关焦点建议、HIG 基础原则并自行设定控制台配色。这些社区技能不等于 Apple 官方认证。

## 审查范围

- `web/styles/design-system.css` 新增共享语义令牌、明暗主题、字体层级、按钮/表单/弹窗/卡片、可见焦点、减少动效和响应布局；七个已有模块样式将常见硬编码颜色接入令牌，删除 Google Fonts 网络导入。
- `web/index.html`、`web/agent-os.js` 增加窄屏抽屉导航、遮罩、inert、焦点循环与恢复、Escape、跳过导航和 aria-current；`web/assistant.ts` 只补充原生模态框名称。
- 检查导航调用方 go()、页面切换事件、断点变化、原生 dialog 打开分支、关闭 details 内控件、键盘正反向循环。既有原生模态框优先管理键盘。详情面板沿用既有 class 开关，默认收起。
- 修复验证中发现的总览 min-content 撑宽、窄屏导航旧布局居中、侧栏 visibility 继承使控件检查不可靠，以及详情默认显示与按钮展开状态不一致的问题。
- 后端只在静态文件精确白名单增加 design-system.css；未开放任意路径，不改 API、鉴权、项目数据、执行、预算、批准或持久化契约。CSS 不接收外部输入。
- `scripts/verification/verify-ui.mjs` 使用既有隔离协议夹具，不使用个人应用数据库；Playwright 为可选验证工具，不添加产品依赖。失败写入报告，finally 关闭浏览器和夹具。
- package.json/package-lock.json 版本同步为 0.1.1，新增浏览器验证命令；Windows 文档更新安装包名称，README 链接设计规范；四张预览为隔离夹具实际截图。
