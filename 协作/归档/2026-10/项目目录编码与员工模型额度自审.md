# 项目目录、Windows 中文输出、员工模型与额度

日期：2026-10-16。分支：`codex/readiness-p0-p2`。本轮由 Codex 完成实现和自审，没有启动额外 Agent；本文不是独立审查或人工批准。

## 范围与实际行为

- 项目添加/编辑提供服务端文件夹浏览器，可以选择磁盘、用户目录、父目录和子目录，并筛选子目录。选择器浏览的是运行 ApiX 的电脑，不依赖浏览器上传目录来猜测绝对路径。
- 新项目可明确勾选“目录不存在时创建目录”；未勾选时不会创建。拒绝空路径、相对路径、文件路径和重复目录，中文及空格目录可用，错误在弹窗内显示。目录使用真实路径，编辑仍受未处理任务的目录修改限制。
- 修复 `localhost` 页面同源请求被硬编码的 `127.0.0.1` Origin 检查拒绝的问题。Host 仍限于本机白名单；Origin 必须与请求 Host 一致，外站与两个别名之间的跨源请求仍拒绝。
- 员工 stdout/stderr 通过 Node 流式 UTF-8 解码，避免一个汉字分散在多个数据块时损坏；末行没有换行的完整 JSON 事件也会处理。两条 HTTP JSON 输入通道也使用流式 UTF-8 解码。
- 员工进程设置 `PYTHONUTF8=1`、`PYTHONIOENCODING=utf-8`；Windows Codex 的任务参考上下文包含 PowerShell 输入输出和文件使用 UTF-8 的约定。不修改用户全局 PowerShell 配置。
- 员工详情可保存 Pi/Codex/Claude 的模型 ID；后续普通任务和难度路由任务均通过 argv 实际指定模型。空模型沿用 CLI 配置。运行中任务不切换模型。
- Codex 可设置固定推理强度或按任务难度自动设置：1–2 → low，3 → medium，4–5 → high，未知 → medium。使用 `-c model_reasoning_effort=...`，不经过 shell 拼接。此设置与员工“推理能力 1–5”是不同字段；旧能力编辑接口不传新字段时保留原设置。启动事件记录实际参数。
- 更换模型时员工详情会清除旧模型的声明费率，避免把旧模型价格用于新模型的费用预测；原费用授权、模型/账户版本指纹、质量门槛和运行中费用预留机制保持有效。
- Codex 的只读 app-server 查询仅发送 initialize、initialized、account/rateLimits/read、model/list；没有开启推理 turn、登录或写配置。查询有 12 秒期限、2 MB 响应上限，同一运行时并发查询合并；退出时回收进程树。只返回额度窗口和模型元数据，不向前端返回认证信息或原始诊断输出。
- 各员工详情展示共享账户人工快照与 API 预算，保留观测时间和未知值。预算跨项目计入同一账户的费用预留、未结算上界和已结算实际金额；存在未知费用记录时剩余预算保持未知。预算展示随页面轮询更新，表单草稿不被轮询覆盖；切换员工后旧异步请求只更新其已脱离页面的节点。

自审结论：本轮范围通过；未发现阻止提交的问题。后续代码变化需重新审查。下列能力边界继续保留，不将其描述为全部 Agent 实时额度和任意模型自动切换已经完成。

- 已经在生产方变为 ASCII `?` 的历史报告不能反向恢复；新代码修复解码和常见 Windows 编码路径，不声称能修复所有外部程序的非 UTF-8 输出。未在用户另一台电脑复现那条原始报告。
- 实时额度接入范围是 Codex 当前 CLI 登录的订阅窗口，多个员工可以共用它；绑定人工账户不切换 CLI 登录。不支持的运行时明确显示未知，可手工维护快照。查询结果不会自动覆盖人工账户或冒认账户映射。
- API 预算不是供应商余额。尚未接入各供应商实际余额/账单查询，也不包含其他应用花费；无法据此承诺所有注册 Agent 都有实时余额。
- 自动设置推理强度不会自动换成另一个模型，也不保证任意模型都支持所有强度；使用模型目录所列能力配置。原有跨员工成本路由仍依赖已声明的能力、工作量、价格和账户信息。
