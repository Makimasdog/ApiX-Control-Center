## A05 缺陷复现与影响

`src/architecture.ts` 的 schema 函数仅检查为非空对象及长度，不验证 JSON Schema 元结构。以下输入仍被接受：

```json
{"request":{"type":"not-a-json-schema-type"}}
{"schema":{"type":123,"required":"not-an-array"}}
```

期望：在冻结契约/派发前拒绝非法 schema。实际：生成合法架构摘要与 digest。风险：无法保证已冻结接口/数据结构规范本身有效，依赖员工和自审可能继承错误契约。优先级建议 P1，作为下一轮生产修复项；本轮按测试范围保留失败证据，没有把断言改成接受非法输入，也没有给回归套件添加“接受非法 schema”的成功用例。

复现：先 `npm run build`，再 `node scripts/probe-architecture-schema.mjs`，当前退出码 **1**。它是独立能力验收，明确保留失败状态，不纳入 `npm test` 的现有回归计数。
