# Agent 供应商中心自审

日期：2026-10-22。执行与审查：Codex 自审，未启动子 Agent；不是独立审查或人工批准。

## 需求与设计依据

用户要求参考 CC Switch，集中管理 ApiX 和各执行 Agent 的供应商，且仅在 ApiX 中生效。用户引文中的 402 是某次请求的上游错误，不据此推断所有本机 CLI 的认证来源，也没有代用户充值、查询付费余额或切换真实凭据。

参考 [CC Switch 供应商切换](https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/en/2-providers/2.2-switch.md) 的“配置目录与绑定分开”交互；没有复制其代码或改写用户全局 CLI 配置。界面使用 ui-ux-pro-max 的表单标签、提交反馈、错误可见性和触控目标建议，沿用现有设计系统。

适配依据来自官方文档：[Codex 配置](https://learn.chatgpt.com/docs/config-file/config-reference)、[Claude 环境变量](https://code.claude.com/docs/en/env-vars)、[Gemini 配置](https://geminicli.com/docs/reference/configuration/)、[Pi 模型配置](https://pi.dev/docs/latest/models-configuration)、[OpenCode 配置](https://opencode.ai/docs/config/)、[Kimi 环境模型](https://www.kimi.com/code/docs/en/kimi-code-cli/configuration/env-vars)。这些参考用于验证覆盖入口，不代表已经实测所有版本的真实 CLI 和收费通道。

## 实现范围

- 新增供应商配置目录、员工绑定、版本冲突检测和增删改接口；提供名称、协议、基础地址、模型及直接密钥输入。协议按运行时过滤，不向自定义适配器宣称未验证的支持。
- 支持 ApiX 应用默认、Codex、Claude、Pi、Gemini、OpenCode、Kimi。ApiX 仍使用原有模型后端；已有对话保留冻结设置，需主动“使用当前应用配置”，没有暗改历史会话。
- Codex Responses 通道使用配置覆盖与环境密钥引用；官方 ChatGPT 登录选项显式指定官方 provider 和认证方式，并移除继承的 API 路由。没有执行登录或读取、复制 auth.json 内容。
- Claude 使用子进程环境和应用内私有会话设置（其中包含所选密钥，用于覆盖旧版 CLI 文件配置），提供标准 x-api-key 与仅 Claude 可用的 Bearer 两种模式；OpenCode 使用进程内联配置；Kimi 使用临时模型环境；Pi 使用应用数据目录中的专用 models.json 与环境引用；Gemini 使用专用 home 与 API 认证设置。传入环境先复制与过滤，未写系统环境或用户全局 CLI 配置。
- 任务执行及 Pi/Claude 无工具规划共用绑定配置。实际 Run 记录供应商 ID、版本、地址、协议与模型，密钥不进入参数和供应商事件。API 通道的额度查询返回未知及来源说明，不把 ChatGPT 订阅额度误当作该通道余额。
- 切换和编辑绑定配置前检查待执行、运行、进程未知及待验收任务；连已标失败但原运行结束未确认的情况也拒绝切换。切换清除原模型费率与账户绑定，保持严格预算和后续重新批准的边界。单独修改员工模型不能绕过供应商绑定。
- 密钥沿用现有本机凭据文件；公开配置只返回 hasKey。地址或协议改变必须重填密钥，避免旧凭据发送到新站点。保留旧凭据引用以兼容历史对话；删除目录条目不撤销平台侧密钥。
- 私有运行配置按供应商版本隔离并原子写入，相同内容不重写，避免并发读取到半个文件或密钥轮换影响在途规划调用。新增 Git 忽略项及打包过滤，排除 provider-runtimes 和凭据 JSON 文件。
- 新增供应商 UI 验证脚本和默认单测入口，版本升为 0.3.0。锁文件仅改根包与顶层版本，没有变更依赖。

## 限制

没有对真实供应商发起收费推理、没有验证平台实际余额、没有运行全量业务测试。六种运行时的覆盖参数按官方接口适配，真实第三方端点和旧 CLI 版本仍可能存在协议差异；系统管理策略也可能限制覆盖，失败时不宣称通道可用。

新构建的 0.3.0 不会仅因源码提交替换已运行的旧版本；安装包未增加代码签名。首个候选包在认证方式补齐后已被取代，交付仅使用 release-0.3.0-delivery 目录中的最终包；自审阶段候选包不作为交付。
