# 自主交付开发与审查

日期：2026-10-13–14。实施与审查：Codex；这是自审，不是独立审查或人工批准。本轮没有启动子 Agent。用户要求先确定模块、接口、数据结构和验收标准，再实现自主质量闭环、难度与成本路由、持续监督，并管理文档和 Git/GitHub。

## 交付范围

- `src/architecture.ts` 冻结模块边界、接口 request/response、共享数据结构、依赖、风险、难度、工作量和实际检查 ID。共享结构不一致、重叠写入路径、循环依赖、未授权检查或未覆盖模块不能派发。所有实现员工收到同一契约；最后追加系统集成任务。
- `src/autonomy.ts` 保存策略、契约、实测、自审和修复记录。宿主通过 Node argv 执行用户授权脚本，保存退出码、输出和代码指纹；ApiX 根据实际代码与测试自审，通过后才冻结交付。失败生成明确修复任务，保留工作区、原始需求及历次证据，重新审批、测试和验收。达到次数/时间/预算边界或状态未知时停下。
- 调度分别处理推理难度、每次输入/输出 Token 与调用数、费率预测。能力是质量门槛，同币种、同模型版本的预测费用用于排序；未知费用不当作零，估算不替代用户批准上界。Pi/Codex/Claude 使用显式模型 argv；未验证模型选择的适配器不能冒充声明模型。
- 按风险持续请求进度。失联、阻塞和超时先停止已知 Run，收到结束状态后才返工或换人。尚未执行的排队任务可在原契约内改派。重启中断验证保留进程信息，需要检查、确认已停止后恢复；确认记录持久化。最终集成验收后会话完成，并发出一次交付通知。
- UI 提供自主策略、契约、实际验收与修复记录，保护输入草稿并转义模型内容。修复详情保留原始证据，主对话使用简洁通知。长指令和契约摘要在详情面板内换行。
- 文档同步到 README、架构文档、功能说明、分支记录及协作索引。无新依赖、不改默认模型、不启用用户实际项目的自动授权。

## 最终 diff 自审

审查范围包含本轮全部新增/修改的源码、调用方、假 CLI、测试、文档及截图，排除本轮开始时已有的 `.gitignore` 修改和用户未跟踪资料。逐项核对：

1. 架构必须先成功校验；规划期间需求、策略或授权版本变化不能继续派发。模块 ID 在计划编辑中保留，集成依赖全部已验收模块。
2. 执行、返工、换人和验收仍受已确认会话、项目权限、员工清单、预算及配置指纹约束。异步检查/审查后重新检查授权和代码指纹。运行后模型或账户变化不能静默通过验收；从未执行的排队任务允许失效员工被合法替换。
3. 检查使用宿主 Node、参数数组和项目内入口，校验 realpath；不执行模型生成的 shell。输出脱敏、环境去除敏感名称、时间与输出有上限。超时只停止本轮已知进程，无法确认结束则保留未知状态，不自动重试。
4. 证据含真实检查、当前模块代码、差异和指纹；员工报告不能代替证据。二进制、截断、超限、冲突和范围外修改不能自动通过。检查修改交付文件会使原指纹失效。
5. 修复在原任务 DAG 节点创建新运行，保留工作区和历史；每次重新授权、预留费用。撤权、人工拒绝、未知进程与代码冲突不会被自动绕过。重启中断验证的停止确认标记不会在下一次重启重新开放已完成目标。
6. 宿主 Git 检查和恢复改用异步 worker，避免同步 Git 长操作阻塞请求；HTTP keep-alive 改为 65 秒，避免长验收阶段的空闲连接重用失败。
7. 检查 UI 内容转义、策略版本、错误路径和最终交付状态；完成通知只在全计划验收后发出。Git 冻结版本与托管工作区交付不等于应用源仓库、部署或自动合并。

结论：本轮自审通过，可作为开发分支交付。最后变更仅为详情面板的 CSS 换行；重新执行静态检查和实际浏览器复验，面板 clientWidth/scrollWidth 均为 324，无横向溢出。最终提交前按明确文件清单检查暂存内容与自审文件哈希一致。

## 未验证与实际边界

本轮没有使用付费真实模型验收新增自主交付流程或大型多模块系统。先前真实 Pi/Codex/Claude 基础协作补验记录仍有效，但不能替代本轮新流程的真实模型质量评估。推理能力、费率由用户声明，工作量由模型估计；未实现供应商自动价表、账单硬限额或自动能力测评。Pi 显式模型参数沿用已有适配调用，当前机器没有独立 pi 命令；Codex/Claude 本机 help 中的参数已核对。

架构最多 24 个模块，统一契约最多 18000 字符；实际代码上下文最多 100 文件/70000 字节，差异仍受原有预览上限保护。超限进入待处理；不能宣称适用所有复杂度。动态重规划限于已确认模块、依赖和员工清单；扩大需求、重画系统架构或引入新账户仍需重新确认。自主质量审查明确标为 ApiX 自审，不能视为独立安全审计。
