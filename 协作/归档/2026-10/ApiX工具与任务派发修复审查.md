# ApiX 工具、派发与界面修复

日期：2026-10-12。基线：`91d169f`。实施与审查者：Codex（单 Agent 自审）。

## 问题与最终行为

原管理 Pi 固定 `--no-tools`，提示词禁止执行成果；工作意图仅在自动协作开启时触发，导致模型把未提供工具误认为无法派发。现在工具权限与派发权限分别执行真实检查。

- 管理推理由服务端传入可信 projectId，进程 cwd 为该项目。请求批准模式不提供工具；只读模式提供 read/grep/find/ls；完全访问的对话提供 read/bash/edit/write/grep/find/ls。规划只提供读取工具，格式整理和会议禁用工具。权限版本变化向活动 Pi 发送 abort，随后超时终止。
- 复用已安装 Git 位置寻找 Windows Git Bash，并仅给 Pi 子进程补充 PATH；解决本机 Git 在 `D:\Git`、Pi 默认仅寻找 Program Files 的情况，不修改系统 PATH 或用户全局 Pi 配置。
- 明确工作请求产生实际计划，即使自动协作关闭也能生成待审任务；未授权不会启动员工。开启后使用所选员工，继续受权限、预算、暂停和并发限制；变更授权后不派发过期计划，交付仍须验收。
- 系统提示要求宿主 JSON。工具完成后若模型返回普通文本，最多增加一次禁用工具的格式整理，保留原任务与真实答复，不重做工具；整理失败仍显示模型错误并进入待处理状态。原经理推理预留覆盖整个推理生命周期，工具循环与格式整理可包含多次模型请求；费用仍未知时保留 unmeasured，不编造实际用量或费用。
- SSE 独立传递工具开始/完成/失败；项目事件账本只保存工具名称和状态，不保存参数、文件内容或命令输出。前端工具活动归属于当前对话，切换时清空旧记录。
- 对话占主区域，工作详情默认收起，关闭按钮/Escape 可收起；工具与自动协作状态常驻。高级调度 JSON 和对话方式移入详情；输入框、滚动区和手机底部导航使用实际可用高度。新增短时出现与聚焦反馈，尊重 prefers-reduced-motion。

## 限制与操作说明

本次没有新增操作系统沙箱；完全访问允许 Pi 文件/命令工具，不保证命令只能访问项目目录。权限撤销是向 Pi 发出中止请求，不能撤销已经发生的写入或保证所有外部子进程已终止。manager 工具写入不自动提交 Git或通过代码验收，用户仍需检查文件差异。额外格式整理可增加延迟与模型费用；不支持工具的模型/供应商仍可能返回错误。

复测时刷新页面；如显示“工具待授权”，在项目设置中检查 ApiX 权限，或按界面明确授权自动协作。只想规划时保持待批准即可。旧的已确认对话仍不能通过聊天扩大任务范围，应调整需求或新建对话。
