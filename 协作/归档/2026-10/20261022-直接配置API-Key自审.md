# 2026-10-22 直接配置 API Key 自审

结论：Codex 实现并自审通过。这是自审，不是独立审查或人工批准。用户要求在应用模型配置中直接填写 API Key，不再填写环境变量名称。本轮提交，不推送。

## 范围与行为

- 预设平台、自定义服务均提供 API Key 密码框及显示/隐藏按钮；提交独立的 apiKey 字段。保存成功清空输入框并恢复隐藏，刷新不回填。留空沿用已有配置；切换自定义服务地址或协议后，不沿用应用保存的旧密钥引用。原有环境变量引用仍兼容。
- `web/model-settings.ts` 负责表单载荷与服务变化判断；`web/coordinator.ts` 覆盖现有应用模型设置入口和保存反馈。连接测试仍须先保存配置并明确批准费用，不改变预算和工具批准规则。
- `src/infrastructure/model-credentials.mjs` 将密钥放在数据目录的独立 JSON 文件，生成不可预测的内部引用；原始密钥不进入模型设置、会话设置或快照。启动加载到宿主环境，沿用既有推理认证和错误脱敏逻辑，保存后即时可用。
- `control-plane.mjs` 仅增加启动加载和存储依赖；协调器先校验服务配置，随后保存密钥，最后写设置引用。失败不替换数据库原配置；极端数据库写入失败可能留下未引用凭据，但不会替换旧密钥。保留旧凭据支持旧会话的冻结引用。
- 密钥校验拒绝空格、控制字符及超过 8192 字符的输入；随机临时文件以 wx/0600 写入后原子重命名，存储错误返回固定文案，不附带凭据。文件载入/解析错误不回显文件内容。
- 复查 `workerEnvironment`：APIX_MANAGER_* 前缀始终剔除，旧会话管理者引用也在既有保护范围内；推理、命令日志与异常继续使用既有脱敏链。没有扩大静态文件白名单或暴露文件读取接口。
- `.gitignore` 排除凭据文件及其临时文件；现有构建不复制应用数据目录，生产包不含个人密钥或 `.env`。版本为 0.1.2，Windows 文档补充存储位置和使用方式。

## 限制

凭据文件与现有 `.env` 一样是本机明文，不是 Windows 凭据保险库；0600 不代表 Windows 上另有独立 ACL 或系统加密。应用数据目录及备份需按凭据对待。未人工操作安装向导，未调用用户真实付费服务；未完成全量协调器测试。安装包仍未签名。当前旧版窗口不会自动热更新，需要关闭后运行 0.1.2。
