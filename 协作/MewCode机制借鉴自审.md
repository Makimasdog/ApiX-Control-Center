# MewCode 机制借鉴：实现与自审

## 范围与结论

本轮由 Codex 完成后端、前端与自审，没有启动子 Agent，不属于独立审查或人工批准。工作分支为 `codex/readiness-p0-p2`，基础提交 `155d9cd`。参考本机 Mewcode `c49794b` 的工具/MCP、上下文、邮箱事件、记忆召回机制，适配到 ApiX 现有 TypeScript 主循环；没有修改 Mewcode。

审查结论：本轮范围内通过，可以本地提交；不推送、不合并。不以测试通过声明任意真实模型或第三方 MCP 服务都能稳定完成所有任务。

## 实现与契约

| 方向 | 本轮实现 | 保留的边界 |
|---|---|---|
| 工具注册与 MCP | 内置工具与外部工具使用统一 Schema 注册表；官方 SDK 1.32.1 接入 stdio / Streamable HTTP；按项目保存配置、显式启用、按用途发现，当前会话仅暴露已发现工具 | 模型仍返回原 JSON 动作；MCP 描述/readOnlyHint 不授予权限；服务配置不是模型工具 |
| 分层上下文 | 完整结果留存 SQLite，预览、SHA-256 与会话引用；模型及界面按引用分页；窗口预算内分批摘要旧历史，保留完整工具执行组、原始请求及当前宿主状态 | UTF-8 字节估算不是供应商精确 Token；无法容纳时明确暂停；不自动删除原始证据 |
| 事件监督 | 协作事件通知主循环，任务/报告/验收快照去重，普通变化去抖、阻塞立即唤醒；持久化每次委派最多六次监督推理，保留周期检查兜底 | 活跃员工执行期间主循环不能并行写文件或重复派发；确定性排队/改派/返工仍由宿主管理 |
| 记忆召回 | 项目内按中文二元词及英文关键词排序，分类、来源、版本、过期提示；Agent 记忆先候选，用户确认后自动召回 | 不跨项目召回，不新增向量服务或额外模型调用；记忆不是授权；用户记忆更新使旧推理决策失效 |

Mewcode 对照入口：`mewcode/mcp/manager.py`、`mewcode/mcp/tool_wrapper.py`、`mewcode/tools/impl/tool_search.py`、`mewcode/context/manager.py`、`mewcode/teams/mailbox.py`、`mewcode/memory/recall.py`、`mewcode/memory/store.py`。本轮借鉴机制，没有复制其 Python 运行时或替换 ApiX 的验收引擎。

## 最终 diff 自审

- 检查全部新增源文件及调用链：`tool-registry`、`mcp-manager`、`assistant-context`、`assistant-memory` → `assistant-loop` → `control-plane` / `server` → `web/mcp-settings` / `web/assistant`；核对入口脚本、依赖锁文件、测试夹具和文档。
- Schema 参数先校验再进入执行和审批；错误参数可由模型修正；同名工具冲突、非法名称、过大 Schema、远程引用均拒绝。校验器有界缓存按名称与 Schema 内容区分。
- MCP 配置使用乐观版本；启用需显式批准；修改/停用清除目录，旧调用批准不再生效。旧请求仍可拒绝，避免无法关闭审批。
- 自审发现并修复并发清理问题：旧版本发现失败不得删除新版本目录，旧调用失败不得关闭替换后的连接。新增实际 HTTP → stdio 服务替换测试，确认新目录及工具调用仍有效。
- stdio 使用绝对入口、直接启动进程；不隐式 shell。环境变量按名字选择，管理者认证与旧员工身份被过滤；HTTP 只允许 HTTPS 或 loopback HTTP，禁用重定向及 URL 内凭据/查询参数。前端转义服务和工具内容，长结果以 textContent 显示。
- MCP 调用失败或取消后记录副作用不确定，暂停且不自动重放；普通用户消息不能绕过检查恢复。显式 `isError` 不在界面显示成功。Windows 在关闭 MCP 时清理专用进程树。
- 完整输出唯一键为会话/事件；多次读取不重执行原工具，不能跨会话获取引用。大结果引用保留退出码、超时、未知状态及验证指纹等关键标记。
- 记忆确认、删除、编辑检查版本；Agent 不能覆盖用户确认内容；跨项目测试不泄漏。修改记忆时使该项目全部会话版本失效，避免执行基于旧记忆的决策。
- 子流程完成仍需真实验收；监督中的 finish 只回到等待，不能提前完成主任务；已有预算、24 步限制、权限撤销、验证指纹与状态未知恢复保护继续生效。
- 前端配置异步响应有项目/版本保护；刷新不覆盖当前配置草稿。大结果查看限定当前会话，不将原文插入 HTML 执行。
- 包锁新增 MCP SDK 及所需传递依赖，原依赖版本未升级。安装时包审计为零漏洞；没有修改全局 npm 配置。
- `.gitignore` 及工作区原有未跟踪说明、技能、测试页面不属于本轮，保留且不暂存。

## 未验证项与已知限制

- 未连接用户另一台电脑的 4173 服务，未部署或改动其生产数据；需要在目标电脑同步本提交、`npm ci` 后重启。
- 未进行真实模型长时间稳定性、真实 Codex/Claude 员工和第三方 MCP 服务的组合压力测试；现有集成测试使用隔离假模型/CLI，MCP 协议和进程实际运行。
- 未实现 OAuth 登录、旧 SSE、MCP resources、sampling、elicitation；每个服务当前最多取首个工具列表响应中的 100 个工具，暂不翻页。
- 外部工具可能操作远程数据并产生服务费用；本地文件指纹不能证明远程业务正确。MCP 进程以本机用户权限运行，项目 cwd/roots 不是系统沙箱。
- 上下文分页偏移采用 JavaScript UTF-16 单位，极少数分页边界可能把 emoji 的代理对分到相邻页；连续读取原文可重组，暂未做字素分页。
- 历史和输出持续保存在本地，未增加自动清理；项目级词法召回暂不等同语义检索或跨项目全局记忆。
- Windows 强制终止整个 ApiX 时无法保证执行信号清理；正常 SIGINT/SIGTERM 有限时关闭，POSIX 后代进程树未在本轮实测。
