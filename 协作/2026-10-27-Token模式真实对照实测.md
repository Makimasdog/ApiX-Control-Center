# Token 模式真实对照实测（Codex 自审）

结论：本次同任务配对中，节省模式总 Token **增加 36.60%**，总耗时增加 2.17%，两组均完成只读任务且 7 项结论正确。目录精简有效，但本例额外上下文补读抵消了收益。单次配对不能证明普遍收益或普遍退化。

## 配置生效问题

用户已将 BAILIAN / qwen3.8-flash 应用到 ApiX。检查 API 确认应用默认配置已更新，但原测试对话仍保存旧 deepseek 模型和含 `{workspaceid}` 的模板地址。已有对话独立保存模型配置，需要点击「使用当前应用配置」，或新建对话。不是这次配置保存失败。

原失败请求未返回 usage，不能当作零用量，不混入本次成功配对。未输出 API Key，未修改用户供应商配置。

首请求真实输入减少 1,022 Token（14.28%），与目录精简方向一致；面板目录估算减少 1,248 不能替代该实测值。标准调用轨迹为三次读文件、一次 read_context、最终回答；节省轨迹为读 package、读 optimizer、补读、读 usage、补读、补读、最终回答。额外轮次及其历史输入使总量上升。
