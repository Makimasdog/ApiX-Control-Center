# ApiX P3 性能基准报告

- 时间：2026-11-21T11:59:25.373Z
- 环境：Node v22.23.3 · win32/x64 (10.0.26200) · AMD Ryzen 7 4800H with Radeon Graphics          · 16 核 · 15.9 GiB 内存 · commit 1543b46
- 参数：cold-starts=3 dispatch=2000 ledger-writes=5000 events=100000 rss-wait-ms=3000

## 测量口径（真实服务 vs 仓库模块）

| 指标 | 运行主体 | 口径 |
|---|---|---|
| 冷启动 | 真实服务 `server.mjs` 子进程 | spawn → `GET /` 首次 HTTP 200（服务无 `/ready` 路由；未认证时 `/` 返回登录页亦为 200） |
| 空闲 RSS | 真实服务子进程 | readiness 后等 3000ms，采样 5 次取中位；Windows 为 tasklist 工作集（近似 RSS） |
| 派活 p50/p99 | 仓库模块（进程内） | 真实 `createTaskScheduler.pump()` 单任务全路径（含同事务账本 append），mock launch，fixture 经 `taskProfile` 校验 |
| ledger 写入 tps | 仓库模块（进程内） | 真实 `createMemory.append()` 逐条自动提交（WAL，synchronous=2） |
| 100000 事件后启动 | 真实服务子进程 | 合成批量种子（非逐条 durable）持久后，全新进程冷启动到 HTTP 200 |

全部数据为隔离临时目录中的合成数据（127.0.0.1，合成所有者令牌），不触碰真实数据目录，不启动外部 Agent。

## 结果

### 真实服务冷启动（ms）

采样：2206 / 2327 / 2208 → 中位 **2208.45**（min 2206.12 / max 2327.46）

### 空闲 RSS

中位 **121.3 MiB**（采样 KB：124244, 124248, 124248, 124248, 124248）

### 派活延迟（真实调度器 + mock launch，ms）

n=2000（另 100 次预热）→ p50 **1.77** · p99 **5.12** · mean 1.88 · max 12.25

### apix_ledger durable 写入

n=5000 → **698 tps**（总耗时 7160.83ms；单条 p50 1.33ms / p99 4.62ms；synchronous=2）

### 持久 100000 条事件后启动

种子耗时 3736.14ms → 冷启动 **2230.90ms**

## 复现

```bash
npm run build
node scripts/benchmark/run.mjs --cold-starts 3 --dispatch 2000 --ledger-writes 5000 --events 100000 --rss-wait-ms 3000
```

## 已知限制

- 单机单次采样，数字随机器/负载波动；CI 趋势对比应固定 runner 规格。
- 派活延迟为进程内模块口径（不含 HTTP 与真实 Agent 启动）；launch 为 mock。
- 事件种子为批量事务合成数据，只用于「持久事件量 → 启动耗时」维度，不代表逐条 durable 写入速度。
- Windows RSS 口径为工作集，与 Linux VmRSS 不完全可比。
