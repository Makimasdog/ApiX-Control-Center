## 检查发现

### P1：平台切换保留旧自定义模型名

位置：`web/coordinator.ts:157`、`:182`。

`change` 处理器重建模型列表和默认环境变量，却不清除或按平台保存 `customModelName`。例如 DeepSeek 填入自定义模型后切到百炼，即使选择 Qwen，保存仍把 DeepSeek 的模型名发往百炼 URL。用抽取的实际前端逻辑和 DOM 桩已复现：切换后自定义名称仍为 `deepseek-custom`。

修复：切换平台时重置自定义名称，或明确保存每个平台的草稿；将表单状态计算集中到一个函数。验收必须覆盖“切换平台 → 选择预设模型 → 保存”的最终 payload。

### P1：配置回填可能改变已保存的 API 协议

位置：`web/coordinator.ts:196`、`:184`。

回填仅以 URL 判断是否属于预设平台，保存预设时强制使用模板的 API 类型。例如自定义设置为 OpenAI 官方 URL + `openai-responses`，刷新后自动回填为 OpenAI 预设，再保存会改成 `openai-completions`。已用实际回填逻辑和 DOM 桩确认 URL 匹配进入该预设分支。

修复：协议不匹配时保持自定义模式，或保留显式协议及平台标识。验收要求“保存 → 刷新 → 再保存”不改变 URL、模型、协议和环境变量名；包括使用预设 URL 的自定义配置。

### P2：回填与手动切换的字段显示不一致

位置：`web/coordinator.ts:166`、`:191–210`。

手动切换本地平台会隐藏 API Key 标签并更新提示；读取已保存配置时不执行这些步骤。刷新本地配置可能显示本应隐藏的 Key 字段，远程配置的提示也不一致。旧的无 URL 的 Pi provider/model 配置没有对应回填分支，页面显示默认配置，再保存可能清空原选择。

修复：初始化和交互共用渲染逻辑；保留旧 Pi provider/model 的查看和编辑入口，或提供明确迁移说明。验收包含本地刷新、远程刷新和旧配置重开保存。

### P2：提供商数据与校验逻辑存在多个来源

位置：`src/model-providers.ts`、`web/coordinator.ts:138`、`src/coordinator.ts:325`、`control-plane.mjs:876`。

前端另写了一份平台表，新增模块没有调用方。模块要求远程服务填写 Key 环境变量，真实保存路径却允许缺失，直到推理调用才报错。因此“保存成功”并不代表具备调用所需配置。

修复：建立统一配置与校验来源，区分“字段有效”“环境变量存在”“实际连接成功”；明确无 Key 的远程服务是否允许。不要为复用模块直接新增不可访问的浏览器 import：当前静态白名单只允许 `dist/web/*.js`，若前端引用共享目录需同时设计公开模块路径。

### P2：平台模板缺少真实可用性证据

位置：两份提供商表、`.claude/MODEL_PROVIDERS.md`。

当前模型 ID 为硬编码示例，未附官方依据、核验日期或接入记录。LM Studio 的“当前加载的模型”实际发送固定字符串 `local-model`，代码未查询已加载模型；Ollama 列表也不能证明本机已安装对应模型。特定平台可能需要账号可用模型或部署 ID，不能仅靠模板保证成功。

修复：逐个平台核对官方模型 ID、端点和协议；允许输入实际模型/部署 ID；本地优先查询模型列表并保留手填。价格和上下文信息需标明来源、日期，无法核实的内容删除或明确标为示例。本次未联网核验模型目录及价格，不对当前有效型号作结论。

### P2：文档示例与实际启动行为不一致

位置：`.claude/MODEL_PROVIDERS.md:129`、`API_VALIDATION_FIX.md`、`server.mjs` 静态白名单。

文档建议创建 `.env` 文件，但当前 `npm start` 和入口没有自动加载 `.env` 的逻辑。验证说明让用户访问 `/test-error-messages.html`，该文件却不在静态白名单，会返回 404。此外手动测试页面会保存配置，不能替代隔离数据库的自动化回归。

修复：采用与实际启动方式一致的环境变量示例；如支持 `.env`，显式实现并验证加载。将错误场景迁入正式测试，不为测试页面扩大生产静态访问面。统一说明远程 Key 必填与本地可留空的条件。

### P2：日志和验收记录不足

`.claude/CHANGELOG.md` 未记录 `0af1b0b`，最新提供商项仍写“待提交”，文档行数描述与提交统计不一致。现有测试包含配置持久化和假 Pi 模型目录生成，但没有覆盖本次平台切换、协议回填和新增错误分支。截图只能说明特定页面的外观，不能证明交互和接入可用。

修复：日志写实际提交、检查结果及限制；补有意义的行为回归；为 CSS 改动记录窄屏、键盘、长文本、错误状态的浏览器验收。
