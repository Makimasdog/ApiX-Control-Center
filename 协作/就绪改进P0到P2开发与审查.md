## 自审

覆盖最终 diff、新文件、调用方、错误路径、数据一致性与访问边界，代码自审通过，可提交开发分支；外部 Claude 联调和视觉验收不标记通过。提交前还须核对暂存内容。

1. 模型不能批准费用或固定指派；提前剥离与协调器既有行为一致，其他能力/路径约束仍严格校验。
2. Codex 仅忽略已观察的字符串重连诊断，不清除终止错误，退出码仍参与成败判断。
3. 交付查询复用原工作区、公共 Git 目录、worktree 登记和临时 index 校验；线程数据库只读，不回填历史 common_dir；同步验收仍允许原回填。检查前后及主线程比对任务/运行/交接版本，审批再次验证文件指纹。
4. 线程槽位在实际退出时释放，构造、消息、执行及提前退出错误均返回失败。120 秒超时中止线程；极端情况下已启动的 Git 子进程与临时 index 仍需检查。冻结和恢复仍同步执行，不能宣称整个控制面已异步化。
5. 历史快照单独查询，跨页不丢较早快照；索引按项目/会话/序号组织，不删除事件。Unicode 字面检索保留项目隔离与最近结果顺序；仍可能扫描项目事件，不冒称全文索引。
6. 就绪提示不代替认证、额度或预算预留，不返回密钥及密钥变量名。前端转义内容、限定动作；项目切换隔离异步结果，对话切换清除旧历史游标。
7. 真实脚本需要 `--approve-cost`，隔离项目/数据，不修改业务项目或全局 CLI 配置；错误脱敏，停止自身运行后退出，无法确认停止时显式记录。
