# P1 Coding MVP — C 命令日志与最小界面自审

A ddfa6fb、B 5b8cb06 之后的独立变更集，Codex 自审。没有另建 Runtime/数据库或改造员工 CLI。

command-logs.ts 复用 assistant_outputs 与日志锚点事件，按 operationId/会话/通道保存受控工件（log- 命名空间）。command-lifecycle 在预览截断前提供 UTF-8 stdout/stderr，命令桥接接入采集；先跨 chunk 保留秘密边界、脱敏，再写 SQLite。每操作正文合计最多 256 KiB；各通道另留 8 KiB 尾部。日志工件总上限 8 MiB、7 天可读期，下次采集清理过期/最旧已结束操作；活动操作不被回收。达到容量、初始化/写入/采集异常时独立报告不完整及原因，执行事实仍分别保存。元数据与 JSON 转义计入工件总配额；这不是整个 SQLite（包括正常历史中已经读取的有界片段）的容量上限。

read_output 只接受本会话 operationId 或 outputRef，不接受文件路径；可选 stdout/stderr、head/tail、offset/limit（最多 6000 UTF16 单元，保证完整字符）。head 正向分页，tail 首次返回最后一页，再向前翻；明确 offsetUnit。支持直接命令、可信检查和历史结果引用的 outputRef。跨会话拒绝，过期/缺失/摘要损坏明确暴露。源文件哈希与保存 JSON 的 savedResultSha256 分开，游标/判定字段不再丢失；日志工件禁止混用 read_context 的不可变分页，且不出现在普通引用索引。

新增 GET /api/assistant/sessions/:id/logs/:operationId，先核对会话，再读受控日志。主 Agent 的模型目录与真实生产装配接入 read_output。现有可信检查仅用批准脚本、退出/终止与版本事实判定，不实现依赖日志内容的检查解析；若未来加入解析器，必须把完整日志纳入其契约，不得根据缺失片段判通过。预览截断独立于命令/检查结果，不能强行显示失败或假称日志完整。

界面仅扩展现有卡片：命令登记、托管身份/启动、结束/待核对、operationId、stdout/stderr 头尾/继续读取及不完整提示；文件范围/版本、编辑冲突、搜索不完整、会话实际差异、交付证据与未正式验收状态。内容统一 escapeAssistant 或 textContent，不插入原始日志 HTML。现有结果引用按钮改称“已保存结果”，不把原来丢失的输出宣传为完整日志。刷新读取同一持久化宿主事实。

修改：command-logs.ts、command-lifecycle、assistant-commands、assistant-context/result/loop、tool-registry、control-plane、server；assistant-view/assistant 与 assistant.css；命令日志/结果/界面测试、共用 Coding 夹具、标准清单和本报告。

失败证据：p1-C-before.log 两项均失败（没有日志工件）；初版采集后 34/36 通过，尾部 API 错从保留尾部的开头分页，修复为倒向分页；长源文件引用先增加失败断言，4/5 通过，修复 SHA/游标传播。容量/保留测试首轮 20/21 通过，固定时间相同时按随机 ID 回收不保证最旧，改按创建时间和事件顺序；没有删除断言/加大超时。最终 Windows、Node 22.19.0 check/build 通过，command-logs/coding-view/coding-baseline/assistant-tools/mew-improvements/coding-bridge 21/21 通过、0 失败/取消/跳过（p1-C-final-v2.log，13.56 秒）；此前含命令桥接和可信验收 39/39 通过（p1-C-focused.log）。实际验证 >25k 输出尾部错误、stderr、重建读取、跨 chunk 密钥、400k 超限保留尾部、36 次容量回收、7 天过期、真实 SQLite 更新拒绝和 XSS/刷新确定性。不是模型成功率证据。

自审范围通过：持久化前脱敏、资源/事实与日志完整性的分离、配额、所有权、不可变引用边界、真实桥接、旧 API/验收兼容及界面安全。D 及最终标准全量测试仍待完成，不作发布放行。工件在工作区外的 SQLite；按用户打开的日志片段仍作为有界工具结果保留在普通历史，不承诺整个数据库 8 MiB。非 UTF-8 二进制终端输出不承诺逐字节保存，当前为 UTF-8 文本 Coding MVP。原来的 3,000 项/8 MiB 验收范围没有改变。
