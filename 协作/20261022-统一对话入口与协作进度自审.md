# 统一 ApiX 对话入口与协作进度：实现和自审

日期：2026-10-22。分支：`qoder/unify-json-contract-provider-center-20261022`。Codex 实现并自审，无额外 Agent；不是独立审查或人工批准。

## 问题与最终行为

用户截图反映两页均提供空白目标输入和发起执行功能。此前移动入口和改名没有消除第二套创建行为。本轮删除协调器前端的 `desktop-start`、`coord-create`、新建对话按钮和对应 POST 创建逻辑，保留协调器后端用于 ApiX 委派及历史流程。

- “与 ApiX 对话”承接 ApiX 新目标的输入与发起；总览的新任务入口、旧全局新对话按钮和兼容事件均导向主对话。
- 原“多 Agent 任务”改为“协作进度”，侧栏、面包屑和页内入口同名。展示当前项目已有流程，键盘可选，选中状态通过 `aria-pressed` 提供。
- 员工活动、任务状态、计划审查直接显示在主区域；记录和当前流程补充默认收起。旧流程的需求确认、计划、交付、恢复、停止及验收控件保留，流程补充不会创建新协调器会话。
- 主对话的协作进度按钮优先打开 `child_session_id` 或最近委派结果关联的真实流程。没有关联时进入项目流程列表。
- 配置检查默认收起，刷新保留展开状态；空状态解释用途并导向主对话，无第二个发起任务输入框。

## 设计依据与检查

应用 apple-design 与 ui-ux-pro-max 技能。参照本地 HIG `sidebars.md` 的明确导航标签、`layout.md / Visual hierarchy` 的按重要性排序和渐进展示，将目标输入与流程监控分工；这些是对 Windows Electron 的设计原则应用，不宣称符合 macOS 平台规范。使用现有样式和表单控件，无新 UI 依赖。

审查全部最终差异、新验证脚本、调用方、已有入口、空状态、项目/流程切换、异步过期响应、草稿、转义、权限及验收边界。只修改前端导航和展示；未改数据库、权限、预算或自动恢复逻辑。自审未发现阻止提交的问题。审查后只添加本记录，暂存前检查最终清单与差异一致。
