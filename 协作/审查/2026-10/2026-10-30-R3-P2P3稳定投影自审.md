## 最终 diff 自审范围与发现

1. **存储与所有权**：新表只附加，不改 assistant_optimization 列。设置版本与 session version 分别校验；当前代由会话/代复合外键约束。帧/引用/水位/指针同 SAVEPOINT，压缩时与原 summary/compacted_through/compacted 事件同步提交。新视图随会话物理删除级联；软删除/owner 仍沿用原路径。原始事件、账本和引用不因回退删除。
2. **实际输入与前缀**：核心/尾部来自相同渲染片段的 UTF-8 边界，不解析用户正文猜测；字符串原空白与 Schema 数组顺序不改。旧核心逐字节是新核心前缀；同代保存后不重算文件池/结果表示。项目指令首次/变更/删除追加版本，固定优先级说明与尾部当前版本可表达完整替换；压缩检查点携带当前有效约束。
3. **字段完整性与安全**：按文档逐字段映射；describe 其余字段保留到尾部。stable 已知事实显式分类，未知 kind 在推理前拒绝，legacy 继续默认保留。固定水位分页到结束；预算事件推进扫描但不移除旧帧。source/text/集合/顺序哈希不一致时停止，不重跑工具。首次与变更后的发现定义保持完整，CURRENT_STATE 列出实际可用版本，旧结果不能冒充当前工具授权。
4. **预算、检查点和失败**：完整工作片段与工具定义纳入实际渲染预算，目标受既有 512 KiB 限制。旧完整工具组走原 compactPrefix；重复引用仅指向当前可见正文，切代恢复或重建。候选不缩小则不提交。失败/无收益跨 resume/重启的持久抑制仍缺失，已明确留给 P4。
5. **只读与访问边界**：stable GET context 不生成帧、代、输出引用或模型调用；尚无代为 null。准备推理前复核知识来源，撤权停止。权限/registry 的实时校验保留，固定目录和旧发现不授予权限。私有帧正文留在原本地数据边界；持久化请求诊断只保存既有白名单哈希/枚举/计数，不新增正文/URL/密钥或其哈希。
6. **诊断与传输**：三协议真实 HTTP body 比较诊断开/关不改正文，哈希与实际发包一致；额外区分 preserved/unreported_change/declared_generation/unknown，同时保留原 history remove/rewrite/reorder。首次/重启/淘汰保持 null。取消、503 重试、准备/诊断保存失败均走既有冻结和传输事实；准备帧不冒充已发送。
7. **前端与旧客户端**：布局选择为可选字段，旧客户端 mode-only 不覆盖策略；旧服务无版本字段时隐藏扩展选项。按会话/任务/请求序列与设置版本防旧响应覆盖；策略/模式/版本/审计原子回滚。诊断继续使用 html 转义，390/1440 宽度无横向溢出。字段与用量未知不补零。
8. **修复的实际问题**：早期分类漏列 compacted/memory_recalled，生产检查点回归发现并补齐；早期删除夹具未先删除旧 outputs 外键引用，修正清理顺序。新增稳定布局后浏览器原 select 定位变为两个元素，改为按 mode 名称定位。自审发现异步 describe 期间新用户消息会令准备快照过期，改为推理前丢弃并重组，legacy/stable 均补回归；权限和记忆在异步读取结束后取快照。未为通过测试削弱恢复或审批门禁。
