# 主会话协作工作台前端自审（2026-10-31）

## 范围与结论

本记录是 Codex 自审，不是独立审查或人工批准。分支：`codex/external-agent-workbench`，基线：`d024df0`。针对用户反馈“启动后仍像 CLI、修改的前端在哪里”，补齐首版欠缺的主会话工作台布局与入口；没有改变默认运行后端或用户现有员工配置。

审查结论：本轮前端范围通过自审与下列本地验证，可提交。不能据此宣称 D0–D4 真实模型、成品安装包或性能验收全部通过。

## 修改范围

- `web/assistant.ts`：工作台从主输入区移至对话顶部；空状态、员工名称/来源、真实状态/待处理数、选中态及管理员工入口；清空会话时清除旧员工与面板；加载失败后恢复刷新。
- `web/agent-run-view.ts`：共用一份 Run 面板，主会话宽屏停靠、窄屏原生抽屉；保持原员工详情/任务 Run 入口；成果快捷定位、关闭/Escape、返回焦点；按 Run 保留当前页面内的指导草稿与重试标识。
- `web/styles/agent-workbench.css`、`web/styles/assistant.css`、`web/index.html`、静态资源映射：工作台样式集中到新文件并删除旧重复规则；沿用现有明暗主题；1100px 切换停靠/抽屉，1800px 起过程和成果分列。
- 新增浏览器验证并加入 `test:ui:agents`、`test:ui:all`；同步 README、使用指南、实施契约、docs/INDEX 与审查导航。

## 自审与修复

检查了最终新增与修改文件、所有 `apix:open-agent-run` 调用方、页面/项目/会话切换、异步读取与错误路径、公开输出插值及指导提交路径。

发现并修复：

1. 清空/切换主会话时员工行和旧子流程响应可能残留：清除列表签名、使展示上下文失效并关闭面板。
2. 列表读取失败覆盖内容后，旧签名可能阻止成功响应重新渲染：错误时清除签名；浏览器注入一次读取错误后恢复真实接口，验证列表恢复。
3. 员工行随状态刷新重建后，关闭面板时旧入口已经脱离 DOM：按相同 Run 找回当前员工入口并恢复焦点。
4. 旧员工/弹窗样式会继续干扰新布局：移除原重复规则，统一由工作台样式负责。

运行、问题、审批、投递与验收仍调用原接口；不新增写入权限或事实源。外部文本经过 html.ts 或 textContent。窗口缩放只移动同一面板 DOM，保留现有输入与展开节点，不重新发送回答/指导。不同 Run 不搬运已提交交互；已接收、已排队、待核对继续沿用原语义。
