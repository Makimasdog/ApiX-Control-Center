# 最终请求诊断实施自审

日期：2026-10-28。执行与审查：Codex 自审，无额外 Agent、独立审查或人工批准。用户选择「先实施最终请求诊断」，本轮交付 RD-01/RD-02 的诊断范围；不实施稳定帧、策略切换或付费实验。

## 范围与设计落实

- 沿用 `codex/token-usage-optimizer`，开始基线 `5bf136b`，工作区起始干净。阅读用户提供的 R2 主方案、细则及历史设计自审，历史基线清单与历史自审保持原样。
- `model-request.ts` 从适配器提取配置校验、三协议 body 和认证准备，纯准备一次 JSON.stringify；旧公开类型/配置函数从原入口重导出，调用方兼容。
- `model-backend.ts` 保证 pending 先登记，准备、同步诊断保存和截止时间/取消检查均在网络构造前。真实发送复用冻结字符串；诊断路径重试不重组配置。一次尝试最多一次结算，预备失败零请求，异步保存回调拒绝使用。旧 SSE、取消、故障分类与清理未知优先级维持。
- `prompt-diagnostics.ts` 比较 wire JSON 与实际 prompt UTF-8 字节；系统、参数及历史聚合哈希独立。精确前缀只取进程内相同范围、已经观察响应头的基线；重试不以自身上一次 attempt 为历史基线。基线最多 8 范围/8 MiB，另有有界淘汰记号。作用域包含项目/会话/路由/用途/布局，配置版本改变不复用身份；重启/淘汰用 null 及原因表示不可比较。
- `prompt-descriptor.ts` 同源构造原提示词和可信区域/白名单字段/事件描述，不从模型或文件正文解析 history 标签。描述 SHA-256 必须绑定实际 prompt。完整事件及区域描述仅留内存，数据库持久化摘要与聚合哈希，不持久化每帧列表。格式纠正、压缩独立用途，使用 opaque-v1，不假称有 legacy 字段定位。
- 附加 SQLite 诊断表通过 usage_id 连接账本，严格验证 pending、attempt、项目、会话和用途。诊断观测与用量结算共用 SAVEPOINT，故障回滚保留 pending；准备保存失败使用既有 accounting_unknown 阻断。GET 只查，当前任务最近 30 条记录可选带诊断，不改变既有汇总。
- 面板展示真实缓存 Token 与诊断证据，区分首请求/重启/淘汰、字节前缀与真实 Token；所有动态字段走 HTML 转义。没有模型/策略开关或自动请求。

## 自审与修正

审查最终新增文件与 diff，追踪 assistant-loop → assistant-inference → inferManager → model-backend → token-usage 的成功、失败和重试路径，以及 context GET → token-usage-view 的访问边界。重点检查无网络副作用的准备阶段、重试基线、错误优先级、作用域隔离、事务回滚、旧调用方和旧记录兼容。

自审修复：宿主字段候选按实际 JSON 键顺序排列；补齐参数删除的变化识别；补齐 Responses/Anthropic SSE 终止状态；历史后段重排跳过未变化的共同前段定位事件；面板将事件标注为候选，并同时展示多种历史变化。对应回归断言已补充。正文仅可来自受信宿主描述，正文中的伪造结构文字不会升级为诊断字段。未发现本轮剩余阻断问题。

全量中的服务启动超时作为本次验收限制保留：它位于协调器夹具启动阶段，尚未进入多运行时测试主体或本轮 assistant 推理诊断；新旧模型发包一致且同用例当前/基线单独复测通过。现有证据不足以把该超时归因于本轮，也不足以认定根因已解决。结合最终定向、兼容性与浏览器验证，本轮诊断变更自审通过；该结论不等于全量测试通过。

## 已知限制与未验证项

- 未做真实供应商冷暖配对，缓存命中率和费用收益未知。历史 7,168 → 4,096 没有同次最终请求证据，不能追溯认定根因；夹具只证明能识别宿主结构变化。
- 未实现 stable-prefix-v1、generation、冻结投影、原生多消息/工具、DeepSeek hit/miss 专用适配或显式缓存控制；设计中这些阶段的 S01–S08 等硬门尚未执行，不宣称整个 R2 已验收。

- 进程重启或字节基线淘汰后不能精确回算公共前缀、逐事件差异；当前 prompt 前缀不含适配器 system，system 变化通过独立哈希和实际 wire 比较体现。
- 配置身份依赖宿主持久配置版本；未知版本保守另建。外部环境变量密钥轮换无法识别为供应商账户切换，重启时无精确基线，不记录真实密钥哈希。
- 会话删除沿用软删除，诊断与账本不自动清理；物理删除用量的外键级联在夹具验证。未改用户数据、未重启真实服务、未部署、未推送或合并。
