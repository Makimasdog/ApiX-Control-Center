# 终端问句接管自审

2026-11-14 · Codex 本地自审 · \`codex/external-agent-workbench\`

真实 Codex CLI 0.167.0-alpha.4.1 已先完成一次主动信箱问答：员工提交问题、领取 README 依据、确认答复，并由宿主检查和模块冻结验证。另有运行没有产生公开问句，也没有形成交付；已按时间上限停止，没有把停止结果当成成功。

首次测试暴露出普通 CLI 只在终端打印问题时，退出码为零会先被当作完成，随后验收失败才进入返工，错失代答时机。现在在完成结算前检查公开输出；只有存在明确带问号的未答问句时，才将该次运行视为未完成。ApiX 使用与原生提问相同的证据范围核查。有唯一依据时，先记录公开问句、答复和来源，再以带“ApiX 已答复终端提问”的修复提示重派原任务。不能回答时写入待办。终端提示、日志、JSON、完成报告和已经编号的引用均不作为提问；每项任务最多自动接管两次。

端到端测试使用真实服务入口、持久化 SQLite、真实任务依赖、Node 验收与冻结；员工输出协议使用确定性本地替身验证接管。最终模块交付通过检查并冻结，集成阶段也经 ApiX 答复后完成并通过验收。测试未用真实付费模型。真实 CLI 的主动信箱探测使用现有登录，未使用真实外部平台或用户项目。

尚未验证终端问句接管在真实 CLI 任意输出格式上的泛化能力，以及模型在较长时间无输出后的继续行为。当前没有新的云端 CI。
