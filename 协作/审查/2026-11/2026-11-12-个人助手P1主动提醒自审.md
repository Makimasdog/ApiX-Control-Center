| 审查范围 | 结论 |
| --- | --- |
| 入口与兼容性 | Gateway 在现有 HTTP 服务绑定回环端口后启动调度，信号退出时停止调度。独立启动命令与桌面托管入口共用实现，保留桌面后端的启动和退出协议。总览新增规则与收件箱。 |
| 调度一致性 | Cron 下一时点、运行记录、Heartbeat 和文件检查点在 SQLite 中持久化。到期记录更新和提醒写入在同一事务，版本条件防止覆盖已修改的规则。暂停和删除停止未来触发，历史运行保留。 |
| 事件与失败 | Git 与邮件按项目、类型、来源及投递 ID 去重。事件收据和提醒原子写入，写入失败后可重试同一 ID。Heartbeat 对无变化和无待办静默，文件检查错误可在规则和收件箱查看。 |
| 访问边界 | API 继承本机所有者认证和 Host/Origin 检查。规则、运行记录与事件按项目限定。文件复用项目路径校验，排除越界和凭据路径，读取文件元数据。事件文本以转义后的纯文本展示。调度只生成本地提醒。 |
