# Agent 对话气泡自审

主对话将当前委派计划中的信箱消息按时间插入对话记录。ApiX 和员工使用各自的头像，左侧气泡标明发送方和接收方。用户使用右侧气泡。员工消息沿用服务端返回的摘要，主对话原文保留。交付连线仍使用协作区的头像位置。

已自审消息来源、会话切换、摘要转义和原有详情入口。构建、静态检查以及 HTML 与界面渲染用例通过。Edge 使用隔离数据库副本和明确标注的演示消息，实测 Agent 气泡进入主对话、左右头像排列与交付光点。截图位于 `.tmp/assistant-acceptance/06-chat-bubbles.png`。

同时运行的文件工具测试有一项报「文件版本变化或超出读取预算」，本次改动集中在界面。真实 CLI 消息收发与全量测试本轮未复测。
