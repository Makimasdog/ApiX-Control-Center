# 多 Agent 自动协作与动态自审

2026-11-14，Codex 自审。范围为工作台分支上的任务委派、调度、验收和主对话协作动态。

- 规划与调度重选使用同一份项目员工名单。自主交付的候选还须通过 ApiX 和员工的交集权限。派发时复查工作流版本，按任务登记版本绑定的授权。独立任务并行进入现有工作区准备，依赖、并发和预算仍由各自的准入条件判断。
- 员工退出后立即触发对应计划的验收循环。验收仍需实际检查与 ApiX 自审通过才冻结交付，失败按既有返工上限处理。周期调度继续检查长时间运行和排队的任务。
- 普通消息沿用项目现有执行方式。修改执行方式后才保存项目权限。操作审批在对话中留有入口，总览可直达审批。员工的原生审批仍由运行时和项目授权决定。
- 协作动态按当前计划读取消息、交付和验收记录。内容按既有规则脱敏，摘要最多显示前 120 字符。代码交接完成后显示真实发送者、接收者、冻结版本及可用文件名。历史交接缺少逐来源文件名时显示冻结版本。动效按记录触发，减少动态效果时保留静态连线和文字。

## 验收

- Windows Node.js 22.23.3 构建、静态检查。协调器定向覆盖一次授权完成派发、实际检查、返工与验收，验证未授权候选不可被重选、权限撤销和并发运行信箱隔离。验收端到端用例将周期监督设为 10 分钟，实际进程结束后在测试时限内完成，证明验收由退出事件触发。Git 交接用例核对接收方使用冻结代码而非来源工作区后来更改的文件。
- 本地 Edge 与 Playwright 通过主工作台、协作导航、项目交付、任务流程及 64 个宽度与主题组合。工作台实际观察到员工消息摘要、长文本截断、交付光点、静态减动效模式，以及既有草稿、审批和窄屏布局。HTTP 与浏览器均使用本地协议夹具和隔离数据目录。
- 未执行全量 CI、付费模型、Electron 安装包和真实外部账号联调。协作动态仅展示 ApiX 已接收的消息和宿主已记录的交付。
