# 真实 Codex CLI 主对话验收（自审）

使用已登录的 Codex CLI 0.167.0-alpha.4.1、普通 CLI 后端、隔离 Git 仓库及 Edge 浏览器。ApiX 的规划、答复选择及质量评语使用确定性本地模型夹具。派工、信箱、证据读取、回执、文件生成、Node 检查和界面均走生产实现。

首轮发现信箱问题只显示通用占位。协作活动现读取实际问题正文。真实复测还发现 Windows 上按路径查询文件时设备号可能为 0，导致文件工具拒绝读取 README，员工问题随后进入人工等待。修复只在 Windows 路径查询返回 0 时忽略该设备号，仍检查文件身份、大小、时间和打开句柄，拒绝符号链接。

构建、静态检查、文件工具、普通 CLI 信箱和终端问句接管回归已通过。真实 CLI 主动发问、领取并确认 ApiX 根据 README 给出的 LF 答复，随后写入 a.txt。模块及集成两项宿主检查均通过，任务均自动验收并冻结，全程未手动答复。

Edge 断言真实信箱问题显示在 LF 答复之前。截图在 `.tmp/real-codex-chat/`。`01-real-question-answer.png` 展示主对话气泡，截屏时前端状态尚未刷新到最终验收结果。 `02-real-delivery.png` 暂停真实交付事件触发的动画并截取中间帧。会话中另有一条超时的进度消息，显示「消息未送达」，员工问答回执有独立的完成记录。
