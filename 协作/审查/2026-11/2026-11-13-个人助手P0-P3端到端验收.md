# 2026-11-13 个人助手 P0–P3 端到端验收

Codex 本机验收与自审。基线为远端 main 的 638a9b1，包含 P0–P3。联合用例启动真实 server.mjs --gateway、HTTP API、SQLite、文件记忆和助手工具循环。模型使用本地 HTTP 协议夹具，微信、Telegram 和 Discord 使用测试进程内的传输夹具，未向平台发送真实请求。

## 联动结果

| 链路 | 结果 |
| --- | --- |
| Web → AgentSkill → 文件触发 | 通过。Web Markdown 和附件进入同一会话，已授权技能走实际助手工具循环，保存文件变更证据。文件创建由常驻 Gateway 检测并写入收件箱。 |
| 助手待回复 → Heartbeat → 收件箱 | 通过。技能执行后的会话进入待回复，推进持久化到期时间后，由实际 Gateway 调度生成提醒。提醒未增加模型调用，已读状态跨重启保存。Cron 补跑、无变化静默、Git 和邮件桥接事件另由现有生产 HTTP 回归覆盖。 |
| Web 会话 A → 重启 → Web 会话 B | 通过。两会话按最近消息显式召回相同的工作记忆和长期 Markdown 记忆。删除工作记忆后，后续召回只返回长期条目。模型请求未携带记忆正文或附件字节。 |
| 三个平台 → Gateway → 隔离会话 → 原渠道回复 | 通过。微信、Telegram、Discord 各完成一条入站文字和原路回复。Telegram 的 Markdown 与文件附件保存在本地，可由所有者在所属会话访问。模型只接收各自渠道文字，未获得记忆、工具或文件。通过 Web 向外部会话发消息返回 403。 |
| 重启与重复投递 | 通过。三平台恢复保存的游标，重复夹具事件未重复推理和回复。技能授权、文件提醒、Heartbeat 提醒、已读状态及删除后的召回跨重启保留。 |
| Web 浏览器 | Edge Headless 1440 px 验证安装和启用技能、发送 Markdown 与文件、下载、记忆召回、收件箱及标为已读。390 px 验证技能状态、新会话、召回和收件箱。两种宽度均无页面脚本错误。 |
