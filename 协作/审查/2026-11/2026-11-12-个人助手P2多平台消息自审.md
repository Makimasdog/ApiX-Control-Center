# 2026-11-12 个人助手 P2 多平台消息自审

Codex 自审。特性分支 feature/personal-assistant-channels 从远端 main 的 f13c05a 创建。该提交合并了 PR #10，两组 Windows 全量检查和覆盖率任务均通过。P2 自审结论为通过，可提交。

| 审查范围 | 结论 |
| --- | --- |
| Web 兼容与数据一致性 | 旧纯文本入口与新入口共用 Web 适配器。消息事件、附件字节与请求 ID 在现有消息保存点内提交，纯文本哈希保持兼容。含媒体消息的幂等比较覆盖格式、附件元数据和字节。 |
| 附件边界 | 附件按会话鉴权，归档或删除关闭访问。白名单图片和音频可预览，其他内容按二进制下载。Web 只渲染经过转义的文本、附件名和有限 Markdown。 |
| 外部渠道权限 | 微信、Telegram 和 Discord 各自使用独立适配器。账号配置与平台游标隔离，精确限定会话和发送者。平台专用令牌由环境传入，媒体下载仅访问平台地址。外部文字对话复用推理预算，模型上下文仅取该会话消息。 |
| 失败与恢复 | 平台游标和投递收据持久化，重复消息复用既有会话请求。出站前记录投递意图，结果未知或中途退出时保留状态供核对。对非准入来源跳过处理，下载失败和超预算附件保留文字提示。 |

- 渠道协议夹具验证微信直聊、上下文回复和 AES 媒体解码，Telegram 游标和图片、文件、语音，以及 Discord 历史游标、媒体域限制和抑制提及。用真实 SQLite 与助手循环验收会话隔离、同一投递不重发及服务重建去重。
