# ApiX 自主澄清与验收自审

2026-11-14 · 本地自审 · 分支 `codex/external-agent-workbench`。保留当前工作区中已有的多 Agent 调度、协作动效和样式修改。

本轮围绕主对话验收、需求澄清、协作草稿和供应商故障恢复。截图是界面复现线索，未打开其中的地址、联系供应商或读写真实账号凭据。

- **验收**：主对话的首次可信契约仍由用户批准。项目已开启自动协作、完全访问和自主交付，且直接使用与项目完全一致的 Node 检查清单时，ApiX 可依据真实通过记录、工作区指纹和完整日志验收本轮可归属的净变更。复用原执行状态门槛，权限变化、验收契约变化、外部修改、未确认副作用和不完整证据不能自动放行。验收与会话完成在同一 SQLite 保存点内登记，记录来源为 ApiX。npm 接入和未授权流程保留人工审阅。
- **澄清**：一条用户消息最多一次结构化只读准备，每次最多三项，只允许本地文件查询和差异，继续经过原有路径、工具和预算门槛。准备完成后先由 ApiX 依据结果判断下一步。确实无法推断的目标、关键取舍可在原输入框回答，候选项按需展开。历史草稿没有足够信息时不会自动选定功能或派发工作。
- **恢复**：认证与模型配置问题在主对话、总览和协作进度分别可见。协作讨论失败保留需求和修订版本。主对话可在修正配置后重试原消息，请求不充当“已检查原进程”，也不清除未确认操作；原模型路由、权限、费用和请求账本仍生效。

本地验证覆盖真实 Node 检查与冻结交付、重启验收不重复、未启用项目仍保留人工审阅、不归属于 ApiX 的外部变化不会自动验收、只读准备后直接完成或继续提问、模型认证失败重试、未配置模型时协作需求保持原版本。另运行现有的可信检查与 npm 回归，以及 Edge 浏览器的工具/知识库与协作导航检查。未使用真实付费模型或真实外部平台，不等同远程 CI。

主循环、推理、交付、规划与协作主回归共 189 项通过；随后用最终业务代码复跑模型传输与推理 26 项、主流程定向 4 项，全部通过。可信检查与 npm 20 项通过，两个 Edge 检查通过，最终 build、check 和 diff 空白检查通过。运行中的项目服务未重启，修改留在本地工作区。
