# 2026-11-12 个人助手 P3 技能生态自审

Codex 自审。特性分支 feature/personal-assistant-skills 从远端 main 的 e10dd77 创建。该提交合并 P2 PR #11，Windows Node 22、Node 24 和覆盖率作业均通过。P3 自审结论为通过，可提交。

| 审查范围 | 结论 |
| --- | --- |
| 清单与热加载 | v1 校验标识、版本、操作及其对应权限。每次列出或执行时读取本机清单。损坏的清单退出执行目录，所有者界面仍可卸载。 |
| 生命周期与数据一致性 | 按项目存放清单，SQLite 授权绑定精确内容版本。首次安装须启用，替换校验预期版本并撤销原授权，卸载先撤销再移除清单。验证权限与日程跨服务重启保留。 |
| 沙箱与访问边界 | JavaScript 在 QuickJS/WASM 执行，宿主未注入文件、进程、网络或模块加载接口。项目文件技能要求真实的授权目录并检查目标实际路径。读取、写入、网络请求和日程各使用显式权限。Brave 密钥和别名不传入员工或 MCP 子进程。 |
| 调用方与错误路径 | 复用所有者 HTTP 鉴权。模型工具沿用访问策略、项目权限、审批、效果收据和文件变更证据，执行前复核技能版本。外部渠道仍使用纯对话执行入口。覆盖未授权、错误参数、版本冲突、只读及目录链接越界。 |
| 界面与市场 | 能力中心提供按版本安装、导入清单、启停和卸载。内置市场发布七个版本固定的技能条目，包含文件操作、网页搜索、JavaScript 和本地日程。 |
