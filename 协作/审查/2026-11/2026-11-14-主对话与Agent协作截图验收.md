# 主对话与 Agent 协作截图验收（自审）

用隔离的本地数据库副本启动当前构建，在 Edge 中打开同项目的主对话。历史独立协作流程的异常自动弹出，显示任务名称和无法创建独立 Git 工作区的原因。点击「查看详细记录」进入对应流程，点击「交给 ApiX 处理」回到主对话确认弹窗。

把一条历史已验收流程关联到副本中的对话后，浏览器显示任务协作图、ApiX 和审查员头像、任务分配及最近往来。历史交付消息已过期，界面显示「消息未送达」。

本地 1440×960 截图位于 `.tmp/assistant-acceptance/`。另向浏览器注入一条标注为「演示事件」的交付活动，确认连线光点启动，并截取动画中间帧。浏览器运行没有页面脚本异常。本轮未重新派发真实 CLI 员工，也未复测外部消息渠道。
