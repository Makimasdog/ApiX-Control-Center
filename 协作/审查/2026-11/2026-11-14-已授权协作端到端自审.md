# 已授权协作端到端自审

2026-11-14 · Codex 本地自审 · `codex/external-agent-workbench`

本地用户实例在 4173 端口重启并返回 HTTP 200；修复完成后再次重启，对话和供应商仍使用原有存储。流程验收使用同一生产入口启动独立实例、临时 Git 项目和持久化 SQLite，模型与员工使用本地测试替身，员工工作区、宿主 Node 检查、过程记录、冻结交付和自动返工走真实实现。不使用用户项目、真实账号或付费模型。

先在测试项目保存员工、检查命令和有限返工权限并重启。单次主对话任务中，ApiX 先读取 README 补足验收依据，再分配员工，真实检查发现问题后自动返工，重新检查并冻结员工及集成交付。修复前，相同项目配置被重复提出时停在 `configure_agents` 手动审批。定位到主循环没有识别这个无变更请求；修复后复用同一份设置，不再写权限、员工档案或自主策略，也不改变返工次数、自动改派和费用边界。

自审检查了主循环调用、工具权限、授权匹配和不匹配路径。复用仅限启用自动协作与自主交付、当前授权仍有效、请求的员工运行时与名单一一对应、所报能力与现有档案相符、检查 ID/参数/时限一致的情况。更改检查时限仍产生审批，不派发；首次授权、知识引用涉及的执行限制、不同权限范围与未知运行结果仍沿用原门槛。未验证真实模型表现，以及员工原生交互中业务选择由 ApiX 自动代答。

最终端到端复测通过：持久化对话记录含 README 读取证据、无人工请求记录；冻结的交付均已验收，主对话待处理列表为空。首次授权、员工档案保护、主对话自动验收和本地澄清的定向回归通过；build、check、diff 空白检查均通过。未推送或合并。
