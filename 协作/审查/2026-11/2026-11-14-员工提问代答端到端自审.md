# 员工提问代答端到端自审

2026-11-14 · Codex 本地自审 · `codex/external-agent-workbench`

原行为：原生员工的每个问题都会直接进入人工待办。现在有效授权范围内的问题先交给 ApiX，最多核查 15 秒。答复的依据可来自委派前本任务的原始消息和最近补充消息、冻结需求、项目 README／适用根目录规则或已授权的验收清单。员工请求和项目资料仅作证据；返回内容须逐题引用可匹配的原文，同一请求必须全部可答，才提交原生回复。

自审覆盖权限入口、错误路径和持久化：复用当前协作模型及已有用量账本；答复时重新校验任务、需求、员工、协作和自主策略版本，复用原生交互回执和幂等键。权限有变化、任务结束或原生接收未确认时不会重发。没有依据、资料冲突、模型不可用、超时或需要新业务决定时保留人工回答入口。操作审批不是代答；不由资料扩权，也不自动处理 CLI 纯文本问题。

端到端使用生产服务入口和隔离 Git 项目：主对话派发原生员工，测试替身通过 Codex App Server 协议提出问题和接收答复，员工实际写文件，宿主实际运行 Node 验收，冻结员工及集成交付。计费选项未冻结时，问题进入原会话待办；用户选定后继续执行并验收。另有 Claude 答案格式、无依据答案拒绝、权限型问句拦截、原生问答和浏览器工作台回归。

未使用真实账号、真实付费推理或外部平台。未运行远程 CI，未推送或合并。

最终复测通过：一组问题分别引用原始消息中的中文要求、README 的 LF 约定、已批准的 `verify.mjs`，无人工待办；缺少计费决定的用例只留一条原问题，人工回复后完成验收。两项协作定向回归、15 项模型与原生运行时回归、Edge 员工工作台回归、build/check 和 diff 空白检查通过。用户实例确认无运行任务后已重启，4173 返回 HTTP 200。
