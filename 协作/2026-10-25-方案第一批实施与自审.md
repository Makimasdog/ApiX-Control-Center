## 2. 审查结论（对最终 diff 逐文件）

- `.github/workflows/ci.yml`：audit 门禁、stale-dist step（在 npm test 之后，此时 dist 已由 pretest 构建）、coverage job 均不改变主门禁行为；曾因编辑失误短暂引入重复 `with:` 行，已当场发现并修复，最终文件已通读确认合法。
- `scripts/check-stale-dist.mjs`：只读扫描 + 非零退出；dist 不存在时（npm ci 后）按通过处理，CI 中在构建后单独 step 跑，语义正确；路径对照用 `.ts/.mjs/.js` 三后缀，避免误报。
- `web/*` 四处修改均为表现层小改：跳过渲染的判定不吞用户消息（`role!=='user'` 守卫）；跳转按钮复用既有导航模式；条件渲染的分支里 `restoreControls` 对 null 按钮已有 `if(test)` 守卫；CSS 规则只作用于非用户气泡。
- `eslint.config.mjs`：`toWarn` 保留 `off` 级别不误升；忽略目录含 `.tmp-desktop/**`（gitignored 打包残留，首跑误入结果后补）。
- `package.json`/lockfile：仅新增 devDeps 与脚本；`engines`、测试清单不变。
- `AGENTS.md`/`README.md`/`docs/INDEX.md`：纯文档；INDEX 引用的路径逐一核对存在。
- 数据一致性/访问边界：无数据库、无 API 行为变更；唯一服务端相关文件（server.mjs）本轮未改动。
