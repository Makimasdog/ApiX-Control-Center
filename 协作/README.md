## 保存规则

- 新审查放 `审查/YYYY-MM/`；历史轮次记录放 `归档/YYYY-MM/`，保留原名与原日期。归档表示退出日常阅读路径，不表示问题已关闭或记录失效。
- 截图放 `截图/YYYY-MM/`，原始数据放 `验收数据/`，由报告链接到证据。
- 维护中的接口说明放 `docs/参考/`，产品说明放 `docs/`；复验脚本放 `scripts/verification/`。
- 日常导航只列当前入口，完整历史清单放月度目录。历史“当前”“本轮”“待领取”只适用于记录当时，不恢复旧任务或旧分工。
- 本机缓存和测试日志放 `.tmp/`，桌面打包保留 `.tmp-desktop/`；归档方法见 [临时产物规则](../docs/目录结构.md#临时产物)。
