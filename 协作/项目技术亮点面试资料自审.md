## 易误述点与错误路径

- ApiX 快照查询不等于恢复完整进程；CLI Adapter/Mailbox/SSE 不冒充 MCP。
- MewCode 的 MCP 本地 Schema 转换不完整，结果转换以文本为主；断线后的下一次连接尝试不冒充本次调用安全重放。
- MCP 工具的保守并发标记不解释成协议限制；模拟 GitHub 工具测试不解释成真实 GitHub MCP 接入。
- DAG 是批次等待，fail_fast 在收集本批结果后处理，不宣称实时补位或立即取消本批任务。
- RLock 限于同实例线程；replace/flush 不冒充跨文件事务、多进程安全或断电强持久化。
- recover 是重新调度，保留 attempt 限制和外部副作用边界；HTTP 入口不宣称自动恢复或完全装配 TUI MCP/worktree 能力。
- 候选人推进中的权限、版本、幂等和审计仅为迁移建议，不宣称已有招聘产品实现。
