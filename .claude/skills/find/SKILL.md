# Find Skill

This skill helps you perform deep searches and analysis across the codebase to find specific patterns, functions, classes, or implementations.

## Usage

When the user asks you to find something in the codebase, use this skill to:

1. Search for specific code patterns, function definitions, or class declarations
2. Find all usages of a particular API or function
3. Locate files containing specific keywords or patterns
4. Analyze code structure and relationships

## Instructions

1. Use Grep with appropriate patterns to search file contents
2. Use Glob to find files matching specific patterns
3. Read relevant files to understand context
4. Provide comprehensive results with file paths and line numbers
5. Explain what you found and its significance

## Examples

- "Find all API endpoints in the project"
- "Find where the UserService class is defined"
- "Find all files that import React"
- "Find all TODO comments in the codebase"
