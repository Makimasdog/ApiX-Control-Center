主调用链：`web/assistant.ts → server.mjs → assistant-loop → 宿主 infer/execute → 模型 API / 项目工具 / MCP / delegate`。复杂委派继续进入 `coordinator → architecture/scheduling → task-scheduler → CLI worktree → autonomy → 实际检查/自审/冻结 → 主循环`。

不编辑 `dist/`；`npm run build` 生成。测试在 `test/`，完整测试清单以 `package.json` 为准。对应实现、证据和未验证项见[变更回顾](../变更回顾.md)与[协作记录索引](../../协作/README.md)。
