# 02 · 目录与模块职责

## 1. 仓库顶层

```text
ApiX-Control-Center/
├── server.mjs               # HTTP 唯一入口：管线、鉴权、路由分发、静态文件
├── control-plane.mjs        # 装配根：SQLite 迁移、服务实例、业务导出
├── agent-discovery.mjs      # 本机外部 Agent 扫描
├── src/                     # 后端领域模块（TS 为主，部分运行中 .mjs）
├── web/                     # 前端源码：index.html、页面 TS、样式、legacy agent-os.js
├── desktop/                 # Electron 主进程、后端启动、开发监听、打包配置
├── scripts/                 # 评测、验证、诊断、维护脚本
├── test/                    # node:test 回归、夹具、手工页面
├── docs/                    # 使用指南、架构、参考、专题与本 Wiki
├── 协作/                    # 审查、验收记录、截图、归档
├── dist/                    # tsc 与前端构建产物（不提交）
└── .tmp*/                   # 本机临时产物（不提交）
```

根目录只保留启动装配入口、包配置、README、许可证与 Agent 规则；业务实现归入 `src/**` 或 `web/**`。

## 2. 后端模块

### 2.1 入口与装配

| 文件 | 职责 | 关键导出 |
| --- | --- | --- |
| [server.mjs](../../server.mjs) | 创建 HTTP 服务；Host/Origin、owner 鉴权、错误映射、静态文件、Agent 通道 | 无（顶层执行） |

## 3. 前端（`web/`）
