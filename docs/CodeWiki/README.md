## 项目是什么

ApiX Control Center 是一个本地优先（local-first）、单用户的多 Agent 控制中心，由四部分组成：

- **Node HTTP 服务**：`server.mjs` 提供本机 API 与静态页面，默认 `http://127.0.0.1:4173/`。
- **SQLite 数据层**：默认 `~/.apix-agent-os/apix.sqlite`，WAL 模式，保存项目、任务、会话、消息、交付证据等全部状态。
- **浏览器工作台**：`web/index.html` + 无框架 TypeScript 模块，按页面自注册渲染。
- **Electron 桌面壳**：`desktop/` 启动同一后端并加载同一工作台。

它同时承担三类能力：

1. **通用助手主循环**（`src/assistant/`）：模型决策 + 宿主工具执行 + 上下文压缩 + 交付验收。
2. **多 Agent 协作编排**（`src/coordination/`）：需求澄清 → 计划确认 → DAG 派发 → 监督 → 验收。
3. **本机 Agent 托管**（`src/agents/`、`src/execution/`）：发现 Pi/Codex/Claude 等 CLI，注册员工，托管运行并恢复。

Token 请求当前保证同一次调用在重试时复用已冻结的请求；跨轮稳定前缀、持久化稳定帧/generation 和供应商显式缓存控制仍是后续设计，不能把规划项当作已实现能力。
