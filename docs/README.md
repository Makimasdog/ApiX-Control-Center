## 维护规则

顶层只维护导航、使用、架构、开发、变更五个入口。操作步骤只写在使用指南；状态机和模块边界只写在架构；专题协议放参考；旧版本记录放归档；面试材料放附录。其他页面通过链接引用，避免再复制一份 Wiki。

移动文件时同步修改相对链接；历史结论保留日期和验证范围。测试计数统一回到变更回顾及原始自审证据，不将历史测试合计成当前通过数。
