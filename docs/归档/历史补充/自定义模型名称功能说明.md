# 自定义模型名称功能说明

## ✨ 新功能

现在每个模型供应商配置中都支持**自定义模型名称**，无需切换到"自定义 URL"就能使用该平台的其他模型。

## 📋 使用方法

### 1. 选择预设供应商

在"ApiX 的推理模型"设置中，选择任意预设平台：
- DeepSeek 深度求索
- 阿里云百炼（通义千问）
- 火山引擎豆包
- OpenAI GPT
- Anthropic Claude
- 智谱 AI (GLM)
- 月之暗面 (Kimi)
- Ollama (本地)
- LM Studio (本地)

### 2. 使用预设模型或自定义

**方式 A：使用预设模型**
- 从"选择模型"下拉菜单中选择
- 保持"自定义模型名称"字段为空

**方式 B：自定义模型名称**
- 在"或自定义模型名称"字段中输入完整的模型 ID
- 预设模型选择会被忽略，使用你输入的名称

### 3. 保存配置

点击"保存模型配置"按钮。

## 🔄 配置加载逻辑

系统会智能识别已保存的配置：

1. **如果模型名称在预设列表中**
   - 自动选中对应的预设模型
   - "自定义模型名称"字段为空

2. **如果模型名称不在预设列表中**
   - 自动选中第一个预设模型（仅作占位）
   - "自定义模型名称"字段显示实际的模型名称

## 🆚 与"自定义 URL"的区别

| 功能 | 预设供应商 + 自定义名称 | 自定义 URL |
|------|------------------------|-----------|
| API 地址 | ✅ 自动配置 | ❌ 需手动输入 |
| API 类型 | ✅ 自动配置 | ❌ 需手动选择 |
| API Key 提示 | ✅ 显示标准变量名 | ❌ 需手动输入 |
| 模型名称 | ✅ 预设或自定义 | ❌ 完全手动 |
| 适用场景 | 同平台的其他模型 | 完全自定义的 API |

## 📝 注意事项

1. **模型名称必须准确**
   - 输入的模型名称必须是该平台实际支持的模型 ID
   - 错误的名称会导致 API 调用失败

2. **API Key 仍需配置**
   - 自定义模型名称不影响 API Key 配置
   - 启动前仍需设置对应的环境变量

3. **优先级规则**
   - 如果"自定义模型名称"有值，使用自定义名称
   - 如果"自定义模型名称"为空，使用下拉选择的模型
