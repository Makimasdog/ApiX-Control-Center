# ApiX 代码索引

## TypeScript 核心

| 模块 | 职责 |
| --- | --- |
| src/contracts.ts | 需求、计划、身份、权限、事件及存储接口 |
| src/apix-agent.ts | ApiX 身份、Pi 推理输入、带证据需求提取、计划校验与规则降级 |
| src/requirement-engine.ts | 五项需求、完整度、冲突和确认门槛 |
| src/coordinator.ts | 多目标会话、沟通、确认、版本化计划、派发、变更与追溯 |
| src/permissions.ts | ApiX/员工权限、版本绑定的执行授权 |
| src/task-tracker.ts | 从真实任务状态派生目标状态 |
| src/memory.ts | 独立事件账本、快照回放、项目检索 |
| src/runtime-adapters.ts | Pi/Codex/Claude 及自定义 CLI 注册、能力和命令 |
| src/agent-mailbox.ts | 每个 Run 的短期员工凭据及身份验证 |
| web/coordinator.ts | 目标、沟通、需求编辑、计划、权限、交付验收、追溯 UI |

## 兼容与基础设施

| 模块 | 职责 |
| --- | --- |
| server.mjs | 协调 API、HTTP 静态文件白名单、SSE、员工凭据路由 |
| control-plane.mjs | SQLite 建表/迁移、模块装配、worktree、进程执行和历史功能 |
| src/task-scheduler.mjs | DAG 调度、失败向下游传播 |
| src/execution-control.mjs | 项目/员工并发准入、版本化暂停设置与额度错误识别 |
| src/code-handoffs.mjs | 托管 worktree 校验、Git 交付冻结、依赖补丁与审查后冲突恢复 |
| src/mailbox.mjs | 共享 mailbox、请求关联、幂等、重试、超时、拦截、交付物和资源租约 |
| agent-discovery.mjs | 本机桌面 Agent 发现 |
| agent-os.js | 项目/员工/记忆管理、消息监督、旧页面兼容 |
| coordinator.css / index.html | 工作台外观和入口 |

调用链：web/coordinator.ts → server.mjs → src/coordinator.ts → 需求/权限校验 → resolveApproval → launch → 外部 CLI。原生运行事件更新任务、写入独立账本；调度器推进依赖，前端展示实际交付物。

不要编辑 dist/；执行 npm run build 生成。旧 Director API 的代码用于兼容和数据保留，新入口走协调系统。历史阶段文档用于追踪早期设计，当前行为以《ApiX协调系统实现》为准。
