## 固定对象与任务集

执行前冻结候选 Git 提交、Node 版本、任务文件/问题/oracle 的 SHA-256、模型 ID/供应商端点/账户配置版本、思考强度、上下文窗口、输出限制及工具/权限版本。配置身份可用随机 ID 与版本关联，不导出密钥、端点或其哈希。四组是 standard+legacy、standard+stable、saving+legacy、saving+stable；同一配对块内只改 promptStrategy，mode、模型和其他参数保持一致。

所有任务使用一次性副本、预先批准的固定检查，不装依赖、不访问外部 MCP、不委派 CLI Agent，不用额外 LLM 评分。冷缓存无法清除时标 uncontrolled；禁止保温、无意义填充、额外摘要或为了提高命中率补发请求。

## 顺序、重复和样本边界

每个任务×mode 是独立配对块：A=legacy、B=stable，各执行两次。预定 T1/standard=ABBA、T1/saving=BAAB、T2/standard=BAAB、T2/saving=ABBA；第二阶段 T3/T4/T5 交替 ABBA/BAAB，执行前写入清单，不能看结果后换序。

每次运行是新会话和相同内容的隔离副本；账户、模型、端点和配置不变。跨会话供应商缓存状态不可控，如实记录。任意失败、超时、重试、压缩/纠错和未完成运行全部保留，不能只选稳定段或末轮高命中样本。每组两次只适合作为先导，不能宣称统计显著或跨任务保证；若需每组至少三次，应另列新增次数和预算，不自动续跑。

### 执行前必须补齐的预算证据

- 固定带版本/日期/币种/单位的人工核对费率快照，覆盖输入、缓存读/写、输出/推理及其他实际计费项。不引用当前未知价格编造预计节省。
- 每次调用前预留可证明的最坏金额 R：`允许次数 ≤ min(剩余请求数, floor(剩余金额/R))`，并同时满足每次运行、配对块、全批的限制。R 必须覆盖完整请求的可计费上限，不能用平均命中率抵扣预留；若预算不支持下一次最坏调用，立即停止。
- 验证提供商真实上下文/输出上限及实际序列化参数。当前适配器只在 Anthropic 路径明确写 max_tokens；不能把上述 8,192 当作 Chat/Responses 已有硬上限。若不能设置/证明输出界限并覆盖最坏价格，**不启动付费实验**；先完成相同参数下的本地发包回归和新的授权清单。
- 本地 Token 估算不是供应商 Token。输入/输出总界限须用已知的请求上限作保守预留，返回 usage 后再核对；无法证明调用前剩余额足够则不发送，不能把事后观察线冒充硬封顶。
- 确认账户供应商侧限额/余额机制和本地预留共同覆盖可能的在途计费；现有 ApiX 预算不是供应商余额或真实账单。不能证明金额边界时不运行，不能以文档金额代替技术控制。

## 停止规则

任一金额、attempt、Token 或时间上限即停止，不自动加预算、重跑未完成样本或切便宜模型。其余停止条件如下：

1. 工具越权、非白名单写入、来源/任务文件 hash 漂移、旧约束重新生效、可信验收作假、跨会话资料串用：停止整个阶段，保存证据，先修复再重新申请。
2. 模型配置/路由/思考/权限版本意外变化、账本保存未知、进程/网络清理未知：停止该批，保留 pending/未知成本；确认前不发后续调用。
3. 同有效输入再次自动压缩、无收益候选仍提交、工具组被拆开或重复引用悬空：停止稳定布局比较，回到本地回归，不继续用付费调用调试。
4. 已完成响应缺有效输入/输出 usage：停止该块的成本对照，修复可观测性后重新审批；缓存分项缺失时只报覆盖率。完整配对块没有可比较缓存计数，就停止缓存收益部分，不额外发保温/探针请求凑数据。
5. 某次任务未通过 oracle：保留失败及全部消耗，不标成功，也不追加未预算模型修复。修复是该任务明确范围且预算尚在时才可继续既定工具流程；涉及宿主缺陷则整块停止。

## 报告与推广门

逐 attempt 关联 usage_id、purpose、任务/模式/策略、generation、已声明边界与传输事实；不保存秘密或隐藏推理。报告全部运行的成功/失败/未运行、总输入/输出/推理、缓存读及成对分母/coverage、请求/补读/压缩/纠错/重试数、耗时、冷暖状态与配对顺序。首请求、同代至少一个合格基线后的稳定段、压缩后恢复分开列出，不能只报峰值。

主目标是正确完成任务的总消耗与可核对费用，输入缓存比例只是解释指标。不平均逐轮百分比，不把 byte LCP 换算成缓存 Token，不用跨 mode/模型总体比例掩盖差异。实际账单未知则费用仍未知；费率快照计算值只标 estimate，不能称 invoice。

所有权限/恢复/事实硬门通过且业务 oracle 不退化后，才讨论是否继续。总消耗未改善、补读抵消收益或样本不足时维持显式试验；10% 可作为后续候选门槛，不能据先导样本承诺统计显著，更不以 90% 命中率为通用验收条件。
