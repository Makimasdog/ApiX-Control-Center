# ApiX 功能与限制

更新：2026-10-18；源码基线 `codex/readiness-p0-p2` / `08bf165`。

| 能力 | 已实现 | 使用边界 |
| --- | --- | --- |
| 独立通用 Agent | ApiX 自身 tool/ask/finish 循环、文件/命令/验证与 Skill | 无需 Pi；模型 API 要可用。循环有步数、时间和批准边界 |
| 多轮对话 | SQLite 持久化、旧事件分页、共享侧栏、草稿与项目隔离 | 归档/删除可恢复；活动或未知任务须先处理 |
| 每对话模型 | 供应商连接快照、模型 ID、强度及版本，子流程继承 | 已核验 DeepSeek Flash/V4 Pro 强度；未知网关使用默认。员工模型单独配置 |
| 项目管理 | 服务端目录选择、创建/更新、Windows 规范身份 | 文件夹位于服务所在电脑；不能创建重复路径项目 |
| 非 Git 项目 | 托管基线快照与隔离 worktree | 仍须安装 Git；快照有排除项和容量/链接限制，不改写原目录 |
| 复杂任务 | 冻结模块边界、接口/schema、数据结构、依赖与验收 | 契约通过不等于需求或实现正确；变更须重新确认 |
| 质量闭环 | 实际检查、代码与指纹核对、ApiX 自审、有界返工、最终集成 | 自审不是独立审查；脚本覆盖不足、未知进程、上限等转待处理 |
| 难度/成本路由 | 独立估计工作量和推理难度，质量门槛后按声明费率排序 | 未知费用不是零；能力档案、费率和模型估计不代表真实性能实测 |
| 额度与模型控制 | Codex 只读运行时查询、账户人工快照、员工模型和 Codex 强度 | 并非所有 CLI 都提供额度接口；未知不能伪装剩余 0%。无自动完整账单同步 |
| 监督与排队 | 关键事件有界唤醒、风险检查点、每五秒复核队列、暂停/改派/恢复 | 不绕过前置 accepted、授权、并发或费用；不是无条件自动重写架构 |
| MCP | 官方 SDK stdio / Streamable HTTP、启用批准、延迟工具发现与版本审批 | 不支持任意旧 SSE/OAuth UI；外部服务不受本地文件路径检查构成的 OS 沙箱保护 |
| 上下文与记忆 | 完整大结果引用、预算压缩、项目内确认后召回 | Token 为估算；不是无限窗口或跨项目向量记忆；候选记忆不是授权 |
| 任务事件 | 类型筛选、搜索、日志折叠与换行、窄屏面板 | 最近最多 100 条已加载事件，不等于可搜索全部历史日志 |
| Git 交付 | 指纹审查、冻结 commit、依赖补丁与冲突阻止 | 不自动应用源仓库、合并、推送 GitHub、发布或部署 |
| 员工通信 | Run 凭据、消息关联、幂等、确认与租约 | 员工须主动轮询；未确认不得声称已采纳指导 |

管理 API 信任本机用户，不是公网多租户服务。目录、worktree 和声明的写入范围不是操作系统级沙箱。停止请求不能保证所有外部副作用已撤销；服务重启不自动接管未知 PID 或重放操作。

模型输出必须经过宿主动作校验；自然语言“验收通过”不等于数据库已 accepted。普通协作的用户验收需要实际差异和当前指纹，自主交付还需要授权脚本、质量审查和集成证据。

验证记录按提交和范围分别看待：[变更回顾](变更回顾.md)。已有确定性测试、浏览器截图和历史真实小任务记录，仍不能保证任意规模系统、任意供应商和任意 CLI 版本都能无感完成。尚无桌面安装包、通用原生会话重连、OS 沙箱或供应商费用硬封顶。
