# ApiX Control Center · 改版设计规范

面向前端工程师的实施文档，不是概念稿。结论都带数值、令牌名、文件路径或命令；能读代码核对的事实都写实测值。

## 一句话结论

以「任务 / Run 生命周期」为唯一主轴，把 11 个页面收敛为 **6 个一级入口**；把已经存在的 24 个产出 HTML 的模块**重新挂载**到 1 个任务页的 4 个标签里；用一套 8pt 网格 + 三档宽度（640/880/1120）+ 一组语义令牌覆盖全部版式；把事件流从平铺改成**过程组 + 三类常驻待办**；73 处绕过令牌的硬编码按 6 个可独立回归的批次清零。

## 实测基线（读代码得出）

| 项 | 值 |
|---|---|
| 页面 | 11 个 `<main id="page-*">`，同 DOM 显隐切换 |
| 侧栏入口 | 9 个，其中 5 个藏在 `<details class="assistant-more">` 里；`workspace`、`director` 无导航入口 |
| 前端模块 | `web/*.ts` 29 个，其中 24 个通过 `html` 标签模板产出 HTML |
| 样式 | `web/styles/` 11 个 CSS；115 处十六进制色值，**73 处绕过令牌** |
| 断点 | 33 个不同阈值（16 个组件级 ≤620、17 个页面级 ≥650） |
| z-index | 10 个散值：1/2/4/5/10/20/21/39/40/100 |
| 已有令牌 | 颜色与阴影齐备（`--accent`、`--surface`、`--text-*` 等 21 个），缺空间、排版、动效、层级四类 |
| 两处对比度缺陷 | 深色 `--border-control` 2.74:1（需 ≥3）；浅色 `--accent-alt` 作文字 3.74:1（需 ≥4.5） |

## 使用方式

1. **B1 先并入令牌**：把 `web/styles/tokens.css` 引入 `web/styles/design-system.css`，既有变量改为引用新令牌（名字与值不变），并修 §3.2.1 两处对比度。跑三条门禁确认无像素回归。
2. **B2 起按批次推进**：每批独立提交、独立过门禁、独立回滚；提交前按 06 §6.8 的清单更新 `docs/INDEX.md` 与 `协作/`。
3. **提测对照 05**：36 格逐格核对，空态与失败态文案必须不同。
4. **收尾用 07**：56 条勾完再算交付。
