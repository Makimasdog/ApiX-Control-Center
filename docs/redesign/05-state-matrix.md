# 05 · 状态矩阵

按合并后的 6 个目标页给出。本地单人应用没有账号权限体系，第六列「无权限/未配置」统一解释为**前置条件缺失**（未接入执行后端、未配置供应商、知识库目录不存在、项目未绑定 worktree）。

各列含义：`加载中` 首次进入无缓存；`空` 请求成功但 0 条；`有数据` 正常态（标注 1 条与 200 条的差异）；`局部失败` 部分区块失败、其余可用；`未配置` 前置条件缺失；`窄屏` 390px 形态（其他状态在窄屏的差异写进对应格）。

## 5.1 总览

| 状态 | 页面长什么样 | 主文案 | 可执行操作 |
|---|---|---|---|
| 加载中 | 页面头正常；待办条隐藏；4 张统计卡骨架（88×28）；「待你处理」3 行任务卡骨架 | — | 全部按钮禁用，区域 `aria-busy="true"` |
| 空 | 统计卡显示 `0`；待你处理区空态；最近交付空态 | 「还没有任务。描述你想让员工做的事」 | `发起第一个任务`（打开命令条） |
| 有数据 | 待办条按三类计数出现；4 统计卡；「待你处理」≤5 条（超出显示 `查看全部 12 条`）；今日用量条；预算卡 | 「今天有 3 件事需要你」 | 点任务卡进详情；`查看全部` 进任务页 |

## 5.8 窄屏与断点的实测依据

| 事实 | 值 | 影响 |
|---|---|---|
| 侧栏宽 | 244px | 1024 视口下主内容仅 732px，任务页必须折叠左列表 |
| 导航折叠阈值 | 现有 760px（`#navigation-toggle`） | 统一到 767（4 档断点），行为不变 |
| `verify-ui.mjs` 审计宽度 | 1440 / 1024 / 768 / 390 | 768 与 390 是硬门禁，必须通过 |
| 表格 | 不缩小字号 | ≤3 列转卡片；≥4 列放 `overflow-x: auto` 容器并可 Tab 聚焦 |
| 抽屉（窄屏） | `sheet`，`min(85vh, 640px)` | 仅上两角圆角，遮罩 z-index 39 |
| 截断 | 标题 2 行 `line-clamp`；路径/ID 单行 `ellipsis` + `title` | 不支持"直接裁掉不加省略号" |
| 触控目标 | ≥32×32，相邻间距 ≥8 | 现有 `.nav-item` 高 40 已满足 |
