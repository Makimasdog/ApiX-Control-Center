- [ ] `[u]` 6 页 × 1440/1024/768/390 × 明暗 = 48 组合，`document.documentElement.scrollWidth <= innerWidth`，无横向溢出（表格自身 `overflow-x` 容器内部滚动不计）。
- [ ] `[u]` `verify-ui.mjs` 的 `overflow` 数组（`right > innerWidth + 2` 且非 `position: fixed` 的元素）为空。
- [ ] `[u]` 同时只有 1 个 `.page.active-page`。
- [ ] `[m]` 主内容宽度：1440 ≤ 1120；1024 ≤ 732；768 ≤ 736；390 ≤ 366（按侧栏 244 与留白实测）。
- [ ] `[u]` 所有 `padding` / `margin` / `gap` 计算值为 4 的倍数（允许 0 与 1px 分隔线）。
- [ ] `[m]` 1024 下任务页左列表折叠为下拉；767 下侧栏为抽屉且 `#navigation-toggle` 可见。

## 7.2 排版与断行

- [ ] `[u]` 正文计算字号 ≥ 14px，行高/字号 ≥ 1.5；表单控件 ≥ 13px。
- [ ] `[u]` 每页 `h1` 数量为 1，层级不跳级。
- [ ] `[m]` 长正文段落 `max-width` 落在 560–620px（约 42 汉字/行）。
- [ ] `[u]` 全站 `text-align: justify` 命中 0。
- [ ] `[m]` 含长 ID 的单元格（`t_7f3a…`、`worktrees/…`）单行省略 + `title`，无 2 字符孤行。

- [ ] `[m]` 中文与拉丁/数字混排时行首无悬空标点（抽 20 段确认，`line-break: strict`）。

## 7.3 颜色与对比度

- [ ] `[u]` `verify-ui.mjs` 的 `contrasts` 报告中 7 组均达标：`text-primary`/`text-secondary` ≥4.5、`text-muted` ≥4.5、`on-accent` ≥4.5、`success`/`warning`/`danger` 对其浅底 ≥4.5。当前实测：17.27 / 5.90 / 5.13 / 4.74 / 6.35 / 4.85 / 5.46 / 5.04。
- [ ] `[u]` 深色独立断言（`colorScheme: dark` 下重跑同一组），当前实测 14.28 / 8.65 / 6.36 / 7.19 / 7.95 / 8.07 / 7.76 / 7.07。
- [ ] `[u]` 控件边框（输入框、复选框、未选中分段）对背景 ≥3:1；深色 `--border-control` 由 2.74 修至 3.33。
- [ ] `[u]` 焦点环对相邻背景 ≥3:1（浅 6.35 / 深 7.18），`outline-offset: 3px` 使环不与边线重合。
- [ ] `[m]` 任一状态除颜色外还有文字；6 个胶囊在灰度下仍可区分。
- [ ] `[u]` `web/**/*.css` 十六进制色值仅出现在 `tokens.css` 与 `tokens.css` 明确列出的例外位置。

## 7.4 键盘与焦点

- [ ] `[u]` 页面第一个可聚焦元素是「跳到主内容」链接，激活后焦点落 `<main>`。
- [ ] `[m]` 仅键盘可完成：切一级入口 → 选中任务 → 切标签 → 开抽屉 → 关闭并回到触发元素。
- [ ] `[u]` 抽屉打开时 `document.activeElement` 在抽屉内；关闭后等于打开它的按钮。
- [ ] `[u]` 抽屉/对话框打开时主体 `inert`；连续 20 次 Tab 不逃出容器。
- [ ] `[u]` `Esc` 关闭抽屉/对话框/命令条且不触发提交。
- [ ] `[u]` 767 以下导航抽屉：关闭后 sidebar `inert`、打开时主体 `inert`、`Esc` 与遮罩关闭均恢复焦点（现有脚本已覆盖，阈值改 767 后仍需通过）。
